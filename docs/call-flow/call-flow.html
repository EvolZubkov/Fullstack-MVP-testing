📊 7. ПОКАЗ РЕЗУЛЬТАТОВ И ОБРАТНОЙ СВЯЗИ
SCORM отображает экран результатов с процентом, баллами, статусом пройден/не пройден
Показ результатов по темам (topicResults) UI render
Обратная связь по непройденным темам (topicFeedback) UI render
Feedback показывается только для тем со статусом passed=false
Рекомендованные курсы (recommendedCourses) UI render
Курсы показываются только для непройденных тем
📄 8. СКАЧИВАНИЕ PDF РЕЗУЛЬТАТОВ
Кнопка "Скачать PDF" доступна когда: попытки закончились ИЛИ тест пройден
Нажатие "Скачать результаты (PDF)" UI click
Показ оверлея "Генерация PDF..." UI render
getBestAttempt() — выбор лучшей попытки из suspend_data по максимальному percent
Инлайн картинок варианта отчёта из файлов шаблона async load
generatePdfHtml() — создание HTML с результатами JS
PDF содержит: заголовок, % и статус, результаты по темам, feedback (для failed), рекомендованные курсы
html2canvas() — рендеринг HTML в canvas html2canvas lib
jsPDF.addImage() + pdf.link() для кликабельных ссылок jsPDF lib
pdf.save("Результаты_TestName_DD_MM_YYYY.pdf") download
Скрытие оверлея загрузки UI render
PDF файл сохранён на устройство

{ totalTests, totalAttempts, avgScore... }

🔍 10. ДЕТАЛЬНАЯ АНАЛИТИКА ПО ТЕСТУ
Выбор теста для детального просмотра UI click
GET /api/analytics/tests/:testId HTTPS
SELECT attempts, answers, topics... SQL
попытки, ответы, статистика по вопросам
Включает: passRate, avgPercent, topicStats, questionStats, scoreDistribution, dailyTrends
200 OK { summary, topicStats[], questionStats[] } JSON
Графики, таблицы, список попыток
📡 11. ПРОСМОТР SCORM ТЕЛЕМЕТРИИ
GET /api/analytics/scorm-attempts HTTPS
SELECT FROM scorm_attempts, scorm_answers SQL
попытки из LMS с lms_user_id, lms_user_name
200 OK { attempts[], packages[] } JSON
Данные пользователя приходят из LMS: learner_id, learner_name, email, org
📥 12. ЭКСПОРТ ОТЧЁТОВ В EXCEL
Нажатие "Экспорт в Excel" UI click
POST /api/export/excel { filters } HTTPS / JSON
Фильтры: testId, dateFrom, dateTo, packageId, lmsUserId, passed
SELECT attempts, answers WHERE filters... SQL
отфильтрованные попытки и ответы
Генерация XLSX через библиотеку xlsx: листы "Попытки", "Ответы", "Статистика"
200 OK + report.xlsx (binary) application/xlsx
Скачивание Excel файла
📊 13. ЭКСПОРТ ДЛЯ LMS (РАСШИРЕННЫЙ)
POST /api/export/excel-lms { packageIds } HTTPS
SELECT scorm_packages, scorm_attempts... SQL
данные по пакетам и попыткам из LMS

imported: N questions

🖼️ 15. ЗАГРУЗКА МЕДИА ФАЙЛОВ
Загрузка изображения/видео/аудио UI upload
POST /api/media/upload (multipart) HTTPS / FormData
Поддерживаются: image/*, audio/*, video/* (до 200MB)
Сохранение в /uploads/media/ с уникальным именем
200 OK { url: "/uploads/media/..." } JSON
Превью медиа в редакторе вопроса
📋 16. ДУБЛИРОВАНИЕ ТЕМ И ВОПРОСОВ
Нажатие "Дублировать тему" UI click
POST /api/topics/:id/duplicate HTTPS
INSERT topic (copy) + questions (copy) SQL
Копируются: тема, все вопросы, рекомендованные курсы
201 Created { topic, questions[] } JSON
🎯 17. АДАПТИВНЫЙ РЕЖИМ ТЕСТА
Адаптивный режим: вопросы выбираются по уровням сложности. Переход на следующий уровень при достижении порога.
Настройка уровней сложности UI
POST /api/tests { mode: "adaptive", adaptiveSettings } HTTPS / JSON
INSERT adaptive_levels, adaptive_level_links SQL
Уровень: minDifficulty, maxDifficulty, questionsCount, passThreshold, feedback, links[]
SCORM: adaptive.js выбирает вопросы по difficulty JS logic
Показ достигнутого уровня + feedback + ссылки на материалы UI render
⏱️ 18. ТАЙМЕР И ЛИМИТ ПОПЫТОК
initTimer() — запуск обратного отсчёта JS
TEST_DATA.timeLimitMinutes — лимит в минутах. При истечении — автозавершение.
hasAttemptsLeft() — проверка лимита попыток JS
Попытки хранятся в cmi.suspend_data. getBestAttempt() выбирает лучшую.
✅ 19. ПОКАЗ ПРАВИЛЬНЫХ ОТВЕТОВ
Если TEST_DATA.showCorrectAnswers=true — после ответа показывается правильный вариант
Подсветка правильных/неправильных ответов UI render
Показ feedback к вопросу (general/conditional) UI render
feedbackMode: "general" — один текст, "conditional" — разный для верно/неверно

INSERT INTO attempts SQL

Интерфейс прохождения теста
POST /api/attempts/:id/finish { answers } HTTPS
UPDATE attempts SET result_json... SQL
