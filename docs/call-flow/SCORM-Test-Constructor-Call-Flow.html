👥 Участники системы (Actors)
👨‍💼
Автор (Author)
Роль: author
  • Создаёт темы и папки
  • Создаёт вопросы (4 типа)
  • Конструирует тесты
  • Настраивает адаптивный режим
  • Экспортирует SCORM пакеты
  • Загружает медиа файлы
  • Импортирует вопросы из Excel
  • Просматривает аналитику
  • Экспортирует отчёты
🎓
Обучающийся (Learner)
Роль: learner
  • Проходит тесты в LMS
  • Проходит тесты встроенно
  • Видит результаты и feedback
  • Скачивает PDF с результатами
  • Получает рекомендации курсов
  • Видит историю попыток
🖥️
LMS
Внешняя система
  • Загружает SCORM пакеты
  • Запускает тесты
  • Предоставляет SCORM API
  • Хранит результаты
  • Передаёт данные пользователя
  • WebSoft, Moodle, iSpring...
📊
Администратор
Роль: author (расширенные права)
  • Просматривает всю аналитику
  • Анализирует статистику
  • Экспортирует отчёты Excel
  • Управляет SCORM пакетами
  • Видит данные из LMS

⚙️ Настройки теста
📝 Основные
Название title: string
Описание description: string
Режим mode: standard | adaptive
Порог прохождения passRule: {type, value}
Контент стартовой startPageContent: HTML
Feedback теста feedback: string
⏱️ Ограничения
Лимит времени timeLimitMinutes: number
Макс. попыток maxAttempts: number
Показ правильных showCorrectAnswers: bool
Показ сложности showDifficultyLevel: bool
Перемешивание shuffleAnswers: bool
🎯 Адаптивный режим
Уровни сложности adaptiveLevels[]
Min/Max difficulty 0-100 для каждого уровня
Вопросов на уровень questionsCount: number
Порог перехода passThreshold: % | abs
Feedback уровня levelFeedback: string
Ссылки материалов levelLinks[]
🔄 Процессы системы (20 этапов)
1
Создание контента
Автор создаёт темы, папки, вопросы (4 типа), настраивает feedback
Автор → Frontend → POST /api/topics, /questions → PostgreSQL
2
Конструирование теста
Создание теста, добавление секций с темами, настройка порогов
Автор → Frontend → POST /api/tests → PostgreSQL (tests, test_sections)
3
Настройка адаптивного режима
Конфигурация уровней сложности, порогов, feedback, ссылок на материалы
Автор → Frontend → POST /api/tests {mode: adaptive} → adaptive_levels
4
Загрузка медиа
Upload изображений, аудио, видео к вопросам (до 200MB)
Автор → Frontend → POST /api/media/upload → /uploads/media/
5
Импорт вопросов
Массовый импорт вопросов из Excel файла
Автор → Frontend → POST /api/questions/import (FormData) → PostgreSQL
6
Дублирование контента
Копирование тем со всеми вопросами, дублирование отдельных вопросов
Автор → POST /api/topics/:id/duplicate → новая тема + вопросы
7
Экспорт SCORM пакета
Генерация ZIP: manifest.xml, index.html, app.js, media, PDF assets
Автор → GET /api/tests/:id/export/scorm → SCORM.zip download
8
Загрузка в LMS
Автор загружает SCORM пакет в LMS, публикует курс
Автор → LMS Admin → Upload SCORM.zip → Publish course
9
Запуск теста в LMS
Learner открывает курс, LMS загружает SCORM в iframe
Learner → LMS → iframe load → SCORM index.html
10
SCORM API Initialize
SCORM подключается к LMS API, получает данные пользователя
SCORM → API_1484_11.Initialize() → GetValue(learner_id, learner_name)
11
Телеметрия Start
SCORM отправляет начало сессии на сервер с HMAC подписью
SCORM → POST /api/scorm-telemetry/start {HMAC} → scorm_attempts
12
Прохождение теста
Learner отвечает на вопросы, таймер, показ feedback
Learner → SCORM UI → timer.js, feedback.js, answers.js
13
Телеметрия Answer
Каждый ответ отправляется на сервер для аналитики
SCORM → POST /api/scorm-telemetry/answer → scorm_answers
14
Завершение теста
Финиш попытки, расчёт результатов, сохранение в suspend_data
SCORM → calculateResults() → saveAttemptResult() → suspend_data
15
Показ результатов и feedback
Экран результатов: %, баллы, статус, feedback по темам, рекомендации
SCORM → resultsPage.js → topicResults, topicFeedback, recommendedCourses
16
PDF экспорт результатов
Генерация PDF с результатами, кликабельными ссылками на курсы
Learner → pdfExport.js → html2canvas → jsPDF → download
17
SCORM Commit & Terminate
Отправка результатов в LMS, закрытие сессии
SCORM → SetValue(score, status) → Commit() → Terminate()
18
Просмотр аналитики
Дашборд с общей статистикой, детальная аналитика по тестам
Админ → GET /api/analytics, /analytics/tests/:id → charts, tables
19
Экспорт отчётов Excel
Выгрузка попыток, ответов, статистики с фильтрами
Админ → POST /api/export/excel {filters} → XLSX download
20
Встроенный Learner режим
Прохождение тестов без LMS прямо в приложении
Learner → Frontend → /api/tests/:id/attempts/start, /finish → attempts
