## 3. Грабли, найденные за этот день

Каждая стоила времени; ни одна не видна из кода.

- **`source_path` эталона указывает в ЧУЖОЙ worktree.** Старт dev из worktree переписывает
  `templates.source_path` встроенных шаблонов на своё дерево, а БД одна на всех. Сейчас
  «Стандартный» смотрит в `.claude/worktrees/editor-e5-naming`. **Перед приёмкой поднимите
  dev из главной копии `C:/Repositories/test-builder` — путь чинится сам.** Перезаливать
  встроенный шаблон не нужно и нельзя (`409`).
- **Правка файла шаблона не видна приложению.** Реестр читает копию в
  `uploads/templates/<id>`, манифест живёт в БАЗЕ. «Сертификация» перезалита скриптом —
  проверяйте, что в реестре именно правленая раскладка.
- **Инкрементальный кэш `tsc` — ОБЩИЙ у всех worktree.** `tsBuildInfoFile` лежит в
  `node_modules`, а он junction на главный репозиторий: `npm run check` может отчитаться
  зелёным по чужому дереву. Проверяйте `npx tsc --noEmit --incremental false`.
- **Точечные прогоны не показывают поломок от нового метода `IStorage`.** Полный прогон
  вскрыл 29 падений там, где точечные были зелёными. Перед вливанием — широкий прогон.
- **Конфликт «весь файл» — это концы строк.** `core.autocrlf=true` плюс `* text=auto`:
  файл, лежавший в репозитории с CRLF, нормализуется при любом `git add`. Лечится слиянием
  по содержанию: выгрузить три версии, привести к LF, `git merge-file` — останутся только
  настоящие пересечения (рецепт сессии Э5).
- **Превью шаблонов — генерируемый артефакт и отстаёт.** Закоммиченные `preview.html` несли
  значения ЧУЖОГО шаблона (у «Сертификации» стояли отступы и градиент «Стандартного»).
  Пересобираются `npm run scorm:previews`; сверять глазами бесполезно, сверяйте с
  источником в `styles/report.css`.
- **Подписи переживают переезд.** За день найдено три: подсказка подытогов обещала экран,
  который их не печатает (Ф-2); баннер полотна и подсказка узла «Обзор» звали вкладку
  «Настройки», которой больше нет. На приёмке ищите такие целенаправленно.
