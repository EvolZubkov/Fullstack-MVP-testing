## 2. Задача

План трека ([plan-tests.md](../specs/sim-scenario/plan-tests.md), раздел 4, пункт 4) требует
кругового теста: тест с темами и сценариями проходит по кругу «сохранение → снимок публикации →
книга Excel → импорт → SCORM-сборка», и пункты, их порядок и свойства на выходе совпадают со
входом. Сейчас есть только тесты звеньев по отдельности.

Книга Excel сценарии НЕ переносит (техдолг №1, отложен владельцем 2026-10-08). Поэтому звено «книга
→ импорт» проверяется в той форме, в какой оно существует: книга обязана НЕ СТЕРЕТЬ пункты-сценарии,
их правила открытия, порядок пунктов и пороги. Переноса сценариев книгой этот тест не требует.

## 3. Что должно пережить круг

Вход — тест режима `standard`, поток `router_by_topics`, с двумя темами и двумя пунктами-сценариями
(один со случайной выдачей, один с фиксированной), где:

- у пунктов задан общий порядок `router.itemOrder` (сценарий стоит между темами);
- у сценария есть правило открытия `after_sections_passed` по теме, у темы — `after_sections_completed`
  по сценарию (без кольца);
- у сценария есть порог `test_scenarios.pass_rule_json` (`custom`, `percent`, 80), у темы — свой;
- у сценария заданы название в меню, обязательность, группа, балл по умолчанию;
- у теста заданы штрафы сценариев (`tests.sim_scoring_json`).

На каждом шаге сверяется одно и то же: состав пунктов, их порядок, правила открытия, пороги,
свойства пункта. На выходе SCORM-сборки — то же в `test.json` пакета (`TEST_DATA`): разделы выдачи
в порядке пунктов, `topicPassRule` у раздела сценария, `flowPolicy.sectionUnlockRules`.

## 5. Ограничения среды

- Полный `npm test` (около 8 минут) и `npm run test:cov` — только с явного разрешения владельца.
  Работать прицельно: `npm test -- <путь>`, `npm run test:it -- <путь>`.
- Два теста `npm run test:it` падают и на чистом `main`: `result-variable-constraints` и `psychoHash`
  в `test-transfer`. Это не регрессия трека.
- `npx vitest run` напрямую падает — только через `npm test` / `npm run test:it`.
- `npm run check` в worktree может «врать зелёным» из-за общего кэша `tsc`; надёжнее
  `npx tsc --noEmit -p . --incremental false`. Каталог `tests/` в `tsc` не входит.
- Коммиты без трейлера `Co-Authored-By`. JSDoc с `@module` в новых модулях, комментарии на
  английском или русском по соседству.
