## 1. Что уже изменилось в продукте

Писать нужно про это — оно сделано и лежит в `main`:

- **Ящик редактора переехал на семь вкладок** (было пять с рейлом внутри «Настроек»):
  Основное · Состав и сценарий · Правила прохождения · Оценка результата · Обратная связь и
  итоги · Оформление · Комментарии. У каждой вкладки свой рейл. Целевое дерево целиком —
  [аудит структуры настроек](../reports/AUDIT_TEST_EDITOR_SETTINGS.md) §3.1, эскизы всех
  состояний — `docs/wireframes/editor-settings-target.html` (34 состояния, приняты владельцем
  2026-09-03).
- **У подтемы (тега вопросов) больше нет вердикта.** Она считается и показывается, но не
  судится: пороги подтем остались в базе как легаси и на вердикт темы не влияют. При
  публикации теста, где пороги были заданы, показывается предупреждение.
- **Обратная связь подтемы появилась** (`test_sections.breakdown_feedback_json`): текст с
  рекомендациями на каждую подтему. Правило выдачи владельца: текст показывается, когда
  результат по подтеме НИЖЕ общего проходного порога теста, — при ЛЮБОМ вердикте, в том числе
  в сданном тесте. Порог в баллах переводится в долю от достижимого; теста без порога условия
  нет, и текст выдаётся везде, где написан.
- **Обратная связь темы теперь ЗАМЕНА, а не сложение.** Задан текст раздела — печатается он;
  не задан — печатается текст темы. Прежде печатались оба подряд, и ученик получал склейку,
  которой автор не собирал. Правится карточкой «По темам»: виден РАЗРЕШЁННЫЙ текст, подпись
  источника («Из темы» / «Задано в этом тесте») и «Сбросить до установок темы».
- **Тексты адаптивных уровней уехали из лестницы** в карточку «По уровням» той же вкладки.
- **Появился реестр «По вопросам»** — только чтение: что написано у вопросов этого теста, с
  переходом в редактор вопроса.
- **Карточка «Блоки итогов» убрана из редактора** (решение 12): группировку тем выполняет
  подтема-тег. Данные уже собранных тестов сохраняются и печатаются, редактор их больше не
  предлагает.
- **Книга Excel:** на листах «Обратная связь» и «Рекомендации» появилась колонка «Подтема» и
  владелец «Подтема» (адрес — «Раздел» + «Подтема»). Раздел, чьи подтемы книга назвала,
  забирает набор из книги целиком; раздел, о подтемах которого она молчит, сохраняет свои.

## 3. Правила оформления (обязательные)

- **Никаких emoji** в файлах `.md` — правило владельца, без исключений.
- Разметка обязана проходить `npx markdownlint-cli2 <файл>` без замечаний.
- Руководство автора собирается в PDF: `npm run docs:pdf`. Проверьте, что собралось.
- Числа и подписи в руководстве стережёт гард: `npm run check:author-numbers`.
- Скриншоты в руководствах — из `docs/guides/images`. Снимать заново только то, что
  изменилось; вкладки ящика изменились ВСЕ.

## 4. Грабли

  (Э5) в момент старта НЕ реализованы. Пишите по факту влитого; про эти два — после того, как

  в коде, спецификациях и в руководстве РАЗРАБОТЧИКА шаблонов. Не унифицируйте их между собой.
- **dev-БД — копия прода**: скриншоты снимайте на своих тестах, а не на живых данных
  заказчика.

  проверка шла по всем четырём трекам сразу, а не по каждому отдельно.
