## 6. Принятые решения

Согласованы с владельцем, молча не переигрывать.

- **Переключателя экспозиции нет.** Контроль защищает банк, а не обслуживает вкус автора;
  «выключенным» состоянием служит отсутствие данных.
- **Предел отношения весов `R = 4`** — системная константа, не настройка.
- **Счётчик не переносится** вместе с тестом на другую инсталляцию (PRD-48): приёмник — другая
  популяция. Глобальная скомпрометированность задания — ДРУГАЯ величина, вводится отдельным полем
  «стартовый износ», если понадобится.
- **Время на ответ показывается медианой**, не средним: распределение тяжелохвостое.
- **Предупреждения при сборке пакета не будет** — окна экспорта в продукте нет, «Экспорт SCORM»
  прямая ссылка на скачивание.
- **PRD-56: два экрана — два вопроса.** Аналитика теста отвечает «хорош ли инструмент», раздел
  «Аналитика» — «что происходит с людьми». Общих блоков не остаётся.
- **PRD-56: срез шире группы** — семь осей, база сравнения, порог наблюдений, разрыв по темам.
  Оргструктуры в продукте нет, разрезы по подразделению требуют отдельной работы.
- **PRD-56: реестр прохождений на `DataGrid`**, назначения без срока в очередь внимания не
  попадают.

## 7. Грабли

- **`npm run dev` здесь без watch.** Серверные правки подхватываются ТОЛЬКО перезапуском. На этом
  теряется время: страница десять минут показывала старое число после починки.
- **Перемешивание проходит как `pick` мимо компилятора.** `PickFn` принимает `(pool, k)`, а
  функция с меньшим числом параметров совместима по типам: старый `shuffle` вернёт ВЕСЬ пул вместо
  `drawCount`. Так вели себя тестовые заглушки — оставались зелёными, перестав проверять размеры
  страт.
- **Пакет ДС называется `@skillum/ui-kit`**, в CLAUDE.md он под прежним именем
  `@universityrt/ui-kit`. Тон текста — `error`, не `danger`; тег красится пропом `tone`, не
  `variant`.
- **Копия ДС для эскизов отстаёт** от `client/src/styles/tb-components.css`: правило
  `.tb-draw-all-row` пришлось переносить руками.
- **Worktree:** `node_modules` — junction на главный репозиторий. Снимать его `cmd /c rmdir` ДО
  `git worktree remove`, иначе удаление идёт по junction и чистит зависимости главной копии.
- **Знаменатель доли выдачи** — начатые попытки за окно, не завершённые. Счётчик пополняется на
  старте попытки; завершённые в знаменателе дали «150% — выдано 3 из 2» на первой же приёмке.
  Тесты на моках этого не видели.
