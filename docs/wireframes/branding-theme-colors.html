Состояния

Холст показывает вкладку «Оформление». Каркас вкладки, подвал редактора и раздел «Шаблон» не меняются — см. approved/prd7-design-tab.html.

СостояниеЧто показаноТребование
s-flat Шаблон тем не поддерживает: раздел «Цвета» — плоский список параметров, переключателя темы нет. В рельсе нет «Макета»: шаблон не объявил там ни одного параметра. 2, 4
s-pinned Шаблон умеет обе темы, автор выбрал «Светлую»: тест у всех открывается светлым. Таблица цветов — та же: она следует поддержке тем шаблоном, а не выбору автора. 1, 3
s-auto Тема «Авто»: тест открывается в теме участника. Таблица идентична состоянию s-pinned — меняется активный пункт переключателя и пояснение под ним. 1, 3
s-branding «Брендирование» после выноса цветов: остаются шрифт и логотип. 0

Дельта к реализованному

Что меняетсяГдеЗачем
Новый раздел рельсы «Цвета» Между «Брендированием» и «Макетом» У цвета логика сложнее переноса значения в рендер: наследование из темы шаблона, формат хранения, значение на каждую тему. В общем списке параметров это не выражается.
Раздел без параметров не выводится Рельса подразделов Сейчас пустой раздел показывается и открывается баннером «в шаблоне нет параметров» — пункт, который ничего не делает.
Переключатель темы теста Первым в разделе «Цвета», только у шаблона с темами Автор решает, фиксировать вид теста или отдать его системной теме участника.
Значение цвета на каждую тему Раздел «Цвета» при теме «Авто» Одно значение не обслуживает две палитры: светлый фон с тёмным текстом даёт нечитаемый экран у части участников.
Происхождение значения: «из шаблона» / «Вернуть из шаблона» Строка цвета Уже реализовано; в шаблоне с темами применяется к каждой теме отдельно.

ЭлементКомпонент DSПримечание
Выбор цветаColorPicker (.ou-color-trigger)Уже используется. Палитра и ввод HEX — внутри поповера компонента.
Тема тестаSegmentedControl (.ou-seg)Три значения в одну строку. Не выводится, если шаблон тем не заявляет.
Таблица цветов по темамTable (.ou-table в .ou-table-wrap)У шаблона с темами — всегда. Заголовок строки — название параметра, под ним описание из манифеста; по колонке на каждую тему, которую шаблон объявил.

Что требуется вне панели

ГдеЧто
Манифест шаблонаПризнак поддержки тем — перечень тем, которые шаблон умеет. Без него платформе неоткуда узнать, показывать ли переключатель и вторую палитру.
Раскладка параметров по разделамЦветовые параметры попадают в «Цвета» по ТИПУ параметра, а не по объявленному разделу: иначе каждый уже загруженный шаблон пришлось бы переиздавать.
Хранение значенийУ шаблона с темами цвет хранит значение на каждую тему, независимо от выбора переключателя: сменив тему, автор не теряет уже подобранную палитру. У шаблона без тем значение одно.
ОтрисовкаВыбранная тема ставится на сцену; при «Авто» переопределения печатаются двумя наборами, под светлую и под тёмную.
ПредпросмотрПоказывает выбранную тему; при «Авто» — обе, переключением.
Шаблон «Сертификация»Декоративная плашка обложки залита фиксированным оранжевым мимо токена основного цвета: при смене цвета кнопок обложка расходится с остальным экраном.
