Пояснения — прохождения и срезы в тесте, уровень вопроса (Э3)

ЭлементПоведениеПримечание
Вкладка «Прохождения» тестаРеестр прохождений внутри теста: тест задан страницей — ни чипа «Тест», ни колонки «Тест». Строка открывает «Детали попытки» — то же окно, что на общем уровнеКнопка «Прохождения теста ›» в шапке теста уходит — стала вкладкой. «Прохождения с ошибкой» ведут сюда с условием по вопросу (Э0.1)
Вкладка «Срезы» тестаСписок по оси и сравнение. Рамка — только период: тест задан страницей. Строка среза ведёт во вкладку «Прохождения» с условиями срезаРешение владельца 2026-10-03: срез без теста существовать не может. Сохранённые срезы в списках — только срезы этого теста
Сравнение срезовПереключатель «Результат и темы / Качество вопросов» под слотами; за ним два существующих расчёта (PRD-56 и PRD-66)«Сравнить срезы» внутри «Качества вопросов» уходит — сравнение одно, во вкладке «Срезы»
Вкладка «Тесты» общего уровняПервая вкладка «Аналитики»: тесты с прохождениями, поиск по названию. Строка открывает уровень теста; туда же ведут значок «Аналитика» в списке тестов и значок в строке реестра. Колонки: прохождений, сдали, средний результат, вопросов под подозрением, последнее прохождениеРешение владельца 2026-10-03: точка входа в аналитику единая. «—» в «Сдали» и «Средний результат» — у измерительного теста нет вердикта; «—» в «Под подозрением» — прохождений мало для расчёта. Э3а; колонка «Вопросов под подозрением» — в Э3б вместе с корзиной внимания
Общий уровеньВкладки «Тесты», «Прохождения» и «Требует внимания». Из реестра ушли «Сравнить со срезом» и «Сохранить как срез» с окном выбора теста; «Сохранить фильтр» остаётсяЭ3а
Значок «Аналитика» в списке тестовВедёт на уровень теста: /author/analytics/tests/:testIdРешение владельца 2026-10-03, отменяет решение Э2 (общий раздел с отбором). Отдельного состояния нет — внешний вид списка не меняется
Вопрос: «Предыдущий / Следующий»В порядке сортировки таблицы, из которой пришли; порядок — в состоянии перехода. Пришли по ссылке — порядок таблицы «Качества вопросов» по умолчаниюЭ3б
Вопрос: меню действийТе же пункты, что в меню строки таблицы вопросов: «Открыть вопрос в теме», «Прохождения с ошибкой», «Исключить из выдачи…» / «Вернуть в выдачу»Подписи — дословно из нынешнего меню строки
Вопрос: «Этот вопрос в других тестах»Тесты, где вопрос выдавался за окно экспозиции, с переходом на уровень вопроса в каждомНужен список тестов: сейчас сервер отдаёт только их число
«Требует внимания» на «Обзоре» тестаПод подозрением, требуют ревизии, исключены из выдачи — счётчики; «Показать» ведёт в свой вид таблицыРешение владельца 2026-10-03: точки внимания уровня теста — качество вопросов. Новых расчётов нет
Корзина «Тесты с вопросами под подозрением»В «Требует внимания» общего уровня: строка на тест, «Открыть» — уровень тестаСистемная очередь показывает, где на уровне теста есть дела, но не разбирает их сама. Стоимость сводки по всем тестам — проверить при реализации
