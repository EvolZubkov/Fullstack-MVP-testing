Правила прохождения

Режим: По темам · строго линейно

Разрешить возврат к неотвеченным вопросамВыключено — строго линейно: пропуск и возврат недоступны, карта-индикатор только показывает прогресс, экран обзора отключён (см. Структура).
Позволить изменять ответ до завершенияПри возврате к уже отвеченному вопросу можно изменить ответ (до завершения раздела/теста).
Доступно только при включённом возврате к неотвеченным (нужна навигация назад). Включите возврат выше.
Показывать корректность ответа ученикуПосле ответа ученик видит, верно ли он ответил. Несовместимо с изменением ответа.
Показывать итоги разделапо умолч. ВКЛНезависимая настройка (работает и без возврата). Только для секционных тестов.
