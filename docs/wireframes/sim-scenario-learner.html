ЭлементПоле API / условиеПримечание
Карточка сценарияtest_scenarios, ключ пункта scenario:<id>, data-item-keyКарточка темы из buildRouterHubHtml без изменений структуры. Дельта: метка «Сценарий» первой в ряду меток, класс router-topic-card--scenario, мужской род подписей («Не начат», «Завершён», «Недоступен», «(необязательный)»)
Название карточкиtest_scenarios.titleНазвание, которое автор задал пункту; какой сценарий выпадет из банка, участник до запуска не видит
Метка лимитаtest_scenarios.time_limit_minutes, иначе settings.limitSeconds сценарияУ случайной выдачи сценарий ещё не выбран, поэтому лимит пункта задаёт автор; без него метки нет
Состоянияте же, что у темыХаб говорит, ЧТО пункт закрыт, а не КАК пройден: «Завершён» с галочкой, без цвета исхода. Повторный вход — по правилу теста «менять ответ»; на эскизе — как у темы, закрыт
Закрыт правиломправило разблокировки пунктаНа эскизе — «после тем 1 и 2». Тот же код isSectionUnlocked, что у тем
«Завершить»стандартный подвалНеактивна, пока не закрыты все обязательные пункты, сценарии считаются наравне с темами
Старт теста «Сценарий»макет start.html шаблона без измененийОписание — задание; «Как проходить» — правила полного экрана; факты — проходной балл, лимит, попытки. «вопросов» не показывается: в тесте один пункт
