Сводка над таблицейFR-11Три счётчика тегами с точкой — как в существующем импорте пользователей. Рядом — число строк файла и число после схлопывания повторов (§5.2)
Колонка выбораFR-12Все строки, кроме ошибочных, выбраны по умолчанию и снимаются вручную. Ошибочные строки — disabled, снять/поставить галочку нельзя
Колонка «Что произойдёт»FR-11, §5.2Причина ошибки И действие для нормальной строки живут в одной колонке: у ошибки причина, у остальных — правило прохода. Отдельная колонка «Причина», пустая у семи строк из девяти, читается хуже
Схлопывание повторов§5.2Не отдельная строка со статусом «дубль»: один адрес — одна строка, факт повтора отмечен в её описании
«Аккаунт с правами» выбирается§5.2, FR-17Это НЕ ошибка: тест назначается, письмо уходит без разовой ссылки. Причина отсутствия быстрой ссылки в письме не раскрывается (§6)
Занятое имя группыFR-14, §5.1Второе состояние переключателя. Ошибка ловится на предпросмотре; поле имени вынесено сюда же, чтобы переименовать не возвращаясь на шаг загрузки. «Пригласить» недоступна, пока имя занято
«Пригласить (N)»§5 п.2N — число выбранных строк. Кнопка внизу панели, рядом с «Назад». Подвал диалога общий на все вкладки и остаётся «Отмена»
