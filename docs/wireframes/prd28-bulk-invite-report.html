Файл со ссылками содержит действующие ключи доступа
Каждая ссылка открывает тест без пароля — храните файл как список паролей. Выгрузка возможна, только пока открыт этот отчёт: сырые ссылки нигде не хранятся, и после закрытия диалога восстановить их нельзя. Позже останется лишь перевыпустить ссылки, а это отзовёт прежние, включая уже доставленные письмами.

ЭлементТребованиеПримечание
Сводка из шести чиселFR-18, §5 п.4Создано, переиспользовано, назначено, писем ушло, не ушло, пропущено. Плитки — как в отчёте существующего импорта пользователей
«Требуют внимания»FR-18Один перечень на две разные беды: пропущенные строки и недоставленные письма. Колонка «Исход» разводит их тоном тега
Недоставка не отменяет ссылку§6Назначение создано, ссылка действует и попадает в выгрузку. Это сказано прямо в причине, иначе организатор решит, что человека надо заводить заново
Предупреждение о ключах§7, FR-19Названы обе причины срочности: файл равносилен списку паролей, и выгрузка живёт только пока открыт отчёт. Сырых токенов в базе нет — хранится только SHA-256
