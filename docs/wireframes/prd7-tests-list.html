Acceptance -- PRD-7 покрытие

КодОписание
—Структура списка: Explorer-модель. Корень "Все тесты" → папки с chevron (expand/collapse, aria-level="2") → тесты внутри папки с отступом и indent-guide (aria-level="3"). Тесты без папки лежат в корне на уровне aria-level="2" рядом с папками -- без псевдопапки "Без папки".
—Папка свёрнута: chevron без rotate, дочерние тесты не рендерятся. Папка раскрыта: chevron повёрнут 90°, тесты видны с indent-line.
—Поиск: переключает дерево в плоский список-выборку (role="list"). Все папки раскрыты принудительно. У каждого результата показывается breadcrumb-путь (папка / тест). Banner с role="status" aria-live="polite". Кнопка "Сбросить" возвращает к дереву.
—Фильтры -- отдельный PRD (placeholder в toolbar, без реализации в текущем scope).
FR-30Удаление только из dropdown, кнопка "Удалить тест..." ведёт к confirmation dialog.
FR-31"Архивировать" в dropdown; кнопка "Архив" в заголовке ведёт к prd7-tests-archive.html.
§1Видимые кнопки на каждой карточке теста (при наведении): Редактировать (#i-pencil), Назначить (#i-users2), Экспорт SCORM (#i-download), Аналитика (#i-chart), Ещё (#i-more).
§1Dropdown «...» содержит: Редактировать / separator / [Опубликовать | Снять с публикации] (контекстно по статусу) / separator / Переместить в папку / Архивировать / separator / Удалить тест... Пункты Назначить, Экспорт SCORM, Аналитика перенесены в видимые кнопки и удалены из dropdown.
FR-08 BRDInline actions (редактировать, назначить, экспорт, аналитика) visible on hover; dropdown через «...» содержит только уникальные операции.
—Кнопка «Папка» в заголовке создаёт новую папку (FR-08 BRD). Dropdown папки: Переименовать / separator / Удалить папку... (всегда активна — оба варианта доступны вне зависимости от наличия тестов).
—Удаление папки — два варианта (реф: PowerPoint «Удалить раздел»): (A) Только папку — тесты перемещаются в выбранное место (Корень или другую папку), кнопка подтверждения — primary; (B) Папку и все тесты — требует ввода точного имени папки в поле подтверждения, кнопка активируется только при совпадении, стиль — destructive.
—Состояния: default (дерево), collapsed (папка свёрнута), search (плоская выборка), Меню: Черновик (dropdown с «Опубликовать»), Меню: Опубликован (dropdown с «Снять с публикации»), Меню папки, Удалить: только папку, Удалить: с тестами, Предпросмотр, Lazy load, Загрузка (skeleton), Пусто.
