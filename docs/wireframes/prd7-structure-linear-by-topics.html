КодОписание
FR-40Вкладка "Структура" показывает read-only индикатор текущего flowMode с подсказкой «задаётся во вкладке Настройки».
FR-41Режим linear_by_topics: зоны «Перед тестом» и «После теста», тематические блоки с вопросами, страницы разных типов (intro/info/summary/html).
FR-42Состояния: Основное, Без страниц, Без тем, Загрузка, Ошибка, Read-only, Смена шаблона (mapping), Сохранено.
FR-43Редакторы страниц: intro (с автопереходом), info, стандартная, summary, HTML.
FR-44Предпросмотр страницы (с отсчётом для auto-advance).
FR-45Dirty форма, валидация, санитизация HTML, удаление, DnD страниц и тем.
FR-46Предпросмотр flow runtime.
FR-47Смена режима: компактный warning-блок с раскрывающимся списком несовместимых элементов.
FR-48Fallback шаблона и элемент недоступен в текущем режиме.
FR-49«Нет тем»: ссылка ведёт на вкладку «Состав» (внутри Drawer), не на отдельную страницу.
