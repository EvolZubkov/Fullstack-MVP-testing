Прогресс-индикатор (карта вопросов)FR-10/FR-11; DS QuizMap shape=circle, компактныйКружки с номерами вместо линейного прогресс-бара (дефолтный шаблон). Статусы in-progress: текущий / отвечен / пропущен / не выдан. Клик по пиллу = БЫСТРЫЙ переход к пройденному (выданному) вопросу — быстрый, но неочевидный способ навигации. Скоуп — текущий раздел (секционные) / весь тест (flat). При ВЫКЛ-настройке (возврат) — read-only (без клика)
Граница навигации (фронтир)FR-10/FR-11Переход возможен ТОЛЬКО к уже выданным вопросам (отвечен / пропущен / текущий). Не выданные (за текущей позицией) заблокированы — клик невозможен. DS-gap: у QuizMap нет locked-статуса точки — добавить в ui-kit
Навигация — два способа (дублируют)FR-08/FR-10(1) Пиллы прогресс-индикатора — БЫСТРО, но неочевидно (клик по точке). (2) Кнопка «Вернуться» → ЭКРАН ОБЗОРА — дольше, но ОЧЕВИДНЕЕ (явный список + переходы). Оба ведут к пройденным / неотвеченным вопросам
Маркировка корректностиFR-10a; showCorrectAnswersПо умолчанию только отвечен/не отвечен. При включённом showCorrectAnswers — три варианта: корректно/некорректно/не отвечен (QuizMap review-режим: is-correct/is-incorrect/is-unanswered)
Кнопки страницы вопросаFR-04c; два действия«Отправить ответ» (СПРАВА; явная фиксация; «Принять» при showCorrectAnswers — фикс + корректность/фидбэк) — доступна при отправляемом ответе. «Пропустить» (СЛЕВА) — переход без ответа. «Вернуться» (СЛЕВА, ранее «К обзору») — ТОЛЬКО при наличии пропущенных, открывает ЭКРАН ОБЗОРА (очевидный способ навигации). При возврате ВКЛ — Пропустить + Отправить ответ; при ВЫКЛ — только «Отправить ответ». Завершения на странице вопроса нет. «Назад» нет — навигация пиллами
ЧерновикFR-03bНачатый, но не отправленный ответ при «Пропустить» сохраняется как черновик (вопрос «не отвечен»); при возврате виден и редактируем; переживает перезагрузку
Экран обзораFR-08/FR-16; системный, шаблонныйСИСТЕМНЫЙ экран; дизайн — через ШАБЛОН (варианты оформления). Очевидная навигация: пиллы-обзор + ЯВНЫЙ список неотвеченных с кнопкой «Перейти» на каждый + «Завершить раздел/тест». В СТРУКТУРЕ теста элемент доступен, если настройка «вернуться» ВКЛ; иначе disabled + комментарий, что для разрешения нужно включить настройку
Модал завершенияFR-09; «перед завершением»По «Завершить раздел/тест» при наличии неотвеченных — отдельный МОДАЛ (не экран): «N без ответа → неверные. Завершить?» (DS ou-modal, иконка-предупреждение). После подтверждения — фиксация, возврат невозможен (FR-06)
Итоги разделаFR-05a; section-results, ОПЦ.После «Завершить раздел» при showSectionResults ВКЛ (дефолт). «Продолжить» → следующий раздел / роутер. Выкл — сразу дальше (итоги только по тесту)
ЗавершениеFR-05/FR-06; явная фиксацияПоэтапно: раздел → (итоги раздела) → следующий; в конце «Завершить тест» → результаты. После фиксации раздел/тест заблокирован, пиллы прошлого раздела недоступны
Router-хаб (свободный порядок)FR-05b; router_by_topicsЭкран выбора темы: завершённые темы ЗАБЛОКИРОВАНЫ (без повторного входа, показан результат), доступные — кнопка «Начать». «Завершить тест» доступно (enabled), только когда все темы пройдены. После «Завершить раздел» внутри темы — возврат на хаб. Пиллы — в пределах текущей темы
Терминология «раздел»зависит от flowMode«Раздел» — только в секционных сценариях (linear_by_topics / router_by_topics). В linear_flat разделов нет: единица — весь тест («обзор теста», «Завершить тест»). Показанный холст — секционный (linear_by_topics)
linear_flat (плоский, без разделов)flowMode; состояние «linear_flat»Единица — весь ТЕСТ: «вопрос N из M» по всему тесту, пиллы по ВСЕМУ тесту («Вопросы теста»), один «Обзор теста» + «Завершить тест». НЕТ router-хаба и итогов раздела; структура плоская (зоны До/После + блок вопросов). Экраны обзор/модал/завершение — как у секционных, но на уровне теста
Адаптивный режимadaptive-sessionВозврат и пропуск-с-возвратом НЕПРИМЕНИМЫ: адаптив строго последовательный (следующий вопрос зависит от ответа). Прогресс-индикатор без навигации (read-only); allowReturnToUnanswered на адаптивные темы не действует
