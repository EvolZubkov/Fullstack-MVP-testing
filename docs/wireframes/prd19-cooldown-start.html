Решение пользователя: «доступен, если технически реализуемо»

Источник

Учебный экран рендерится ШАБЛОНОМ (PRD-12), не DS. Здесь — реальная разметка start.html дефолтного шаблона + его theme.css/base.css. Действия start-test / view-results — реальные; download-report, блоки .start-prior / .start-cooldown и светлые токены — добавка реализации F2 (на токенах шаблона).

Контракт состояния F2 (новые поля + гейтинг layout)

Новые поля контекста (builder buildStartState, shared/template/start-state.ts + context.ts) и блоки start.html, которые их гейтят. CSS-классы — в base.css на токенах шаблона. Источник данных различается по хостам (см. «Паритет хостов»).
