Пояснения — Wireframe

ЭлементПоле API / условиеПримечание
Как автор сюда попадает «Тесты» → строка теста → иконка действия Обе поверхности открываются ИЗ СПИСКА ТЕСТОВ: диаграмма ведёт в аналитику теста (страница), карандаш — в ящик редактора (поверх списка). Отдельного экрана экспозиции нет и не заводится
Вторая величина в карточке задания exposurePercent = выдач / попыток теста за окно FR-31. Встаёт рядом с существующей долей верных, в тот же правый край. Пара читается как диагноз: «трудное и заезженное» и «трудное, но свежее» требуют разных действий
Подпись «выдано N из M» deliveredCount / attemptsInWindow Абсолютные числа обязательны: 80% при пяти попытках и при пятистах — разные утверждения
Медиана времени на ответ scorm_answers.latency_ms, медиана по ответам за окно Пакет меряет время показа вопроса с 2026-09-12 (СУММУ всех заходов, PRD-54 §7.2); импорт выгрузки читает ту же колонку. Веб-прохождения времени не дают вовсе, поэтому у метрики СВОЙ объём выборки — он и стоит подписью «по N ответам». Медиана, а не среднее: участник, открывший вопрос и ушедший на обед, сдвинул бы среднее на минуты и выставил задание трудоёмким
Прочерк вместо времени latency_ms IS NULL у всех ответов задания Пакеты, собранные раньше, время не сообщают; ноль здесь означал бы «ответили мгновенно», что неправда
Тон величины ≥ 70% — warning, иначе muted Порог показывает выработку банка, а не дефект задания, поэтому красного тона здесь нет
Тег «ещё в N тестах» otherTestsCount > 0 FR-32. Без него задание, растиражированное соседним тестом, выглядит редким
Строка «всего N показов» globalDeliveredCount Показывается только вместе с тегом: именно это число, а не долю по тесту, берёт вес выдачи
Прочерк вместо процента счётчик пуст (пакет старее 2026-09-12 либо данных ещё нет) «Не учтено» и «ноль показов» — разные вещи, и ноль здесь был бы ложью
Хвост сводки свёрнутой темы ожидаемая экспозиция = drawCount / poolSize FR-33. Сводка «N вопросов в банке · выдаётся M» уже существует — дельта в один хвост, поэтому цифра видна без разворачивания всех тем
Баннер под «Вопросов в тест» та же величина, порог ≥ 70% Данных НЕ требует — считается из настроек, поэтому работает и на пустом тесте. Величина показывается ВСЕГДА: выше порога — баннер warning, ниже — баннер info. Молчащего состояния нет: автор должен видеть цену своей выдачи, а не только тревогу
Предупреждения при экспорте НЕТ — FR-33a. Окна экспорта в продукте не существует: «Экспорт SCORM» — прямая ссылка на скачивание. Окно ради предупреждения добавило бы лишний шаг в частую операцию по всем тестам; величина уже показана дважды в редакторе. Снято 2026-10-05 (Э5 UX-аудита аналитики, решение владельца Р6): окно «Сохранить как…» есть (approved/e5-export.html); предупреждения об экспозиции в нём по-прежнему нет — это отдельное решение
Экрана настройки поправки нет — Решение владельца: контроль экспозиции защищает банк и переключателя не имеет. Показываем только факты
