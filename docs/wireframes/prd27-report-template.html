Что здесь показано

Дельта PRD-27 — одна новая карточка в блоке обратной связи вкладки «Настройки» и одно модальное окно. Окружение (карточка «Общая обратная связь теста», оболочка редактора, вкладки) перенесено 1:1 из approved/prd7-editor-settings-tab.html и настоящим PRD не меняется.

Соответствие требованиям

ЭлементТребованиеПоведение
Селектор «Вид отчёта» FR-12 Виды, объявленные АКТИВНЫМ шаблоном для режима этого теста. Подписи из манифеста; подсказка называет шаблон-источник
Блок «Параметры вида» FR-13 Только поля settings[] выбранного вида, в объявленном порядке. Типы отображаются теми же контролами, что поля страницы (PRD-22)
Предупреждение при смене вида FR-14 Значения полей с совпадающими ключом и типом переносятся, остальные отбрасываются; отбрасываемые перечислены по именам
Сообщение «видов нет» FR-15 Вместо селектора: отчёт соберётся по виду «Стандартного» с оформлением этого теста. Предпросмотр доступен и показывает именно этот результат
Действие «Предпросмотр отчёта» FR-17, FR-21 Открывает окно с СТРАНИЦЕЙ отчёта, а не с PDF-файлом: ни растеризации, ни скачивания
Содержимое предпросмотра FR-18 Название теста и темы — настоящие; баллы, вердикты и обратная связь демонстрационные. Слушатель обозначен нейтрально, персональные данные не используются
Переключатель исхода FR-19 «Не пройден» / «Пройден»: меняются вердикт, цвета и наличие блока рекомендаций
Метка «Образец» FR-18, FR-21 Тег в шапке окна: показанные показатели нельзя принять за результат реальной попытки
Открытие по несохранённым правкам FR-20 Окно строится на текущем состоянии формы, включая несохранённые значения полей
Адаптивный тест FR-11, D-5 Тот же блок предлагает виды ТИПА report.adaptive; виды обычного режима в списке не появляются, и наоборот
Размещение карточки §7.1 Блок обратной связи «Настроек», следом за «Общей обратной связью теста»: отчёт — обратная связь обучающемуся, а не параметр оформления

Чего в эскизе намеренно нет

Страница отчёта внутри окна предпросмотра показана заглушкой: её вёрстка принадлежит ШАБЛОНУ, а не этому экрану, и эскизом не задаётся. Сегодняшний вид отчёта — в спецификации §6.2: перенос в макеты «Стандартного» обязан воспроизвести его без изменений.
