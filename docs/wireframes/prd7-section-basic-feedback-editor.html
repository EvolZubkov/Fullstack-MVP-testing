Acceptance -- PRD-7 покрытие

КодОписание
FR-36Feedback-редактор поддерживает три формата: plain (textarea), richText (toolbar: bold, italic, link, list, ordered-list), html (raw textarea + предпросмотр). Переключение формата сохраняет содержимое.
FR-36Секция "Ссылки" (test_feedback_links / links[]) доступна во всех форматах: список строк "подпись / URL" с кнопкой удаления и "Добавить ссылку".
FR-36Секция "Файлы для скачивания" (feedback_assets) доступна во всех форматах: список файлов с именем, размером и кнопкой удаления; кнопка "Прикрепить файл" с подсказкой о допустимых форматах и ограничении размера. Файлы отображаются в предпросмотре как ссылки для скачивания с иконкой и размером.
FR-36Предпросмотр показывается для форматов richText и html; plain-формат не нуждается в отдельном предпросмотре.
FR-36HTML-режим показывает предупреждение о безопасности содержимого.
—Пустое состояние: placeholder-текст в области ввода; счётчик символов 0/max; секции ссылок и файлов показывают empty-state текст.
—Контекст теста (s-richtext, s-plain, s-html, s-empty): редактор открывается из вкладки Настройки → Обратная связь, карточка "Общая обратная связь теста"; поле tests.feedback, ресурсы feedback_assets с scope=test.
—Контекст темы (s-topic): редактор открывается из вкладки Состав, карточки темы, поле tests.topics[].feedback; ресурсы feedback_assets с scope=topic. Разметка редактора идентична тестовому контексту, отличаются только заголовок и контекстная строка.
NFR-21Toolbar-кнопки имеют title и aria-pressed; область ввода имеет aria-label и aria-multiline; счётчик символов -- aria-live="polite".
