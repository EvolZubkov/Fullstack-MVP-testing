Acceptance — FR-36, NFR-21 покрытие

КодОписание
FR-36Три формата: plain (textarea), richText (toolbar + contenteditable), html (raw textarea + предпросмотр). Переключение формата сохраняет содержимое.
FR-36Секция «Ссылки» доступна во всех форматах: список пар «подпись / URL» с удалением и «Добавить ссылку».
FR-36Секция «Файлы для скачивания» (feedback_assets): список файлов с именем, размером и удалением; кнопка загрузки с подсказкой по форматам и ограничению. Файлы отображаются в предпросмотре как ссылки.
FR-36Предпросмотр: для richText и html; plain не нуждается в предпросмотре.
FR-36HTML-режим показывает предупреждение о безопасности содержимого.
—s-empty: placeholder в редакторе, счётчик 0/max, empty-текст в секциях ссылок и файлов.
—s-topic: редактор открывается из вкладки Состав, карточки темы. Разметка идентична тестовому контексту, отличаются заголовок и строка контекста.
NFR-21Toolbar-кнопки: title, aria-pressed. Область ввода: aria-label, aria-multiline. Счётчик: aria-live="polite".
