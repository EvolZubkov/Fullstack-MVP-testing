PRD-46 — роза расклада по шкалам

Вид диаграммы — «роза». Круг равен всему профилю, сектор равен доле стиля, пунктирное кольцо — ровный расклад по 25 процентов на стиль. Два стиля выпирают за кольцо, два проваливаются внутрь: это и есть вывод методики. Цифр на диаграмме нет — значение печатает карточка справа.

Те же четыре значения, нарисованные радаром. Слева предел оси — домен шкалы: он равен 98, потому что отвечает на вопрос «сколько набрал бы стиль, забравший весь бюджет», и фигура сжимается в пятно. Справа автор задал предел показа 40. Данные не изменились, изменился масштаб; подпись предела стоит под диаграммой, потому что иначе две картинки нельзя сравнить.

У «Вдохновляющего» видимость «только уровень»: автор скрыл балл. Роза показывает доли целого, а доля скрытого балла — тот же балл в других единицах, поэтому диаграмма не строится. Ученику она просто отсутствует, карточки остаются на месте; автору редактор называет причину.
