Acceptance — PRD-7 покрытие

КодОписание
FR-04Статус валидности секций виден на табах (dirty / warning / error); кнопка "Сохранить" блокируется при критичных ошибках.
FR-05Закрытие редактора через крестик; confirmation dialog при dirty оформляется в отдельном wireframe (prd7-editor-close-confirm.html).
FR-05aВ state "Ошибки" кнопка "Сохранить" disabled, баннер с переходом к первой ошибочной секции.
FR-05bВ footer нет кнопки "Сбросить всё".
FR-25aЕдинственный primary action "Сохранить" для всей draft-модели.
FR-25bАгрегированные индикаторы dirty/warning/error на табах и локальные индикаторы в секциях; всё с aria-label.
FR-25c, FR-25c1, FR-25c2Кнопка "Показать изменения" видна только при dirty. Клик открывает popover с группировкой изменений по вкладкам и diff-визуализацией старое → новое.
FR-43Wide Drawer min(1120px, calc(100vw - 48px)); вкладка "Настройки" с двухпанельным side nav на >=960px и аккордеоном на <960px.
NFR-19Фокус при открытии переходит в drawer body (tabindex="0"); крестик закрытия имеет aria-label.
NFR-20Drawer использует семантику role="dialog" aria-modal="true"; tab trap описан в коде Drawer-обёртки.
NFR-21Индикаторы состояния (.status-dot.dirty/.warn/.error) дублируют цвет через aria-label на родительском tab/badge.
