Acceptance — FR-04, FR-05, FR-25, FR-43

КодОписание
FR-04Статус вкладок через status-dot (dirty / warn / error); Сохранить блокируется при ошибках.
FR-05Закрытие через крестик; confirmation dialog при dirty — см. prd7-editor-close-confirm.html.
FR-05aПри ошибках Сохранить disabled; DS Banner с кнопкой перехода к ошибке.
FR-25aЕдинственный primary action «Сохранить» для всей draft-модели.
FR-25bАгрегированные индикаторы dirty/warn/error на вкладках с aria-label.
FR-25c«Показать изменения» только при dirty; popover группирует изменения по вкладкам.
FR-43Drawer min(var(--wf-size-1120), 100vw-var(--ou-space-9)); Настройки — side-nav ≥ var(--wf-size-960), аккордеон < var(--wf-size-960).
NFR-19Фокус при открытии — drawer-body (tabindex="0"); крестик с aria-label.
NFR-20Drawer: role="dialog" aria-modal="true".
NFR-21status-dot парный с aria-label на родительской вкладке.

Пояснения — Wireframe

Элемент Поле API / условие Примечание
Состояния wireframe showState(btn, stateId) Метанавигация переключает только визуальные состояния и не является частью продуктового UI.

DS Mapping

Заполняется после gate этапа 3, до старта frontend (этап 3.5). Строка с «custom» в колонке DS-компонент является блокером.

Элемент wireframe DS-компонент Используемые токены Примечания
Метанавигация состояний Wireframe utility --ou-space-*, --ou-border-*, --ou-accent-* Не мигрируется в продуктовый UI.
