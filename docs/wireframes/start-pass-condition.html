Какая плитка при какой политике

«Тест пройден, если»Плитки условия
Только общий результат«N% — проходной балл» (как сейчас)
Общий результат и обязательные темы«N% — проходной балл» и «K из K — обязательных тем для прохождения»
Все обязательные темы«K из K — обязательных тем для прохождения»; общий процент не показывается (2.34.1)
Все темы«M из M — тем для прохождения»

K — число обязательных тем теста, M — число тем с порогом. Плитка скрыта, если таких тем нет. Измерительный тест (без оценивания) условий не показывает, как сейчас.

Для шаблонов: новое необязательное поле контекста course.passCondition ({ count, total, kind: "required" | "all" }); шаблон без него показывает обложку как раньше. Меняется контракт шаблонов (минорная версия): плитка добавляется в default, certification, corporate, minimal и rtk-storyline.
