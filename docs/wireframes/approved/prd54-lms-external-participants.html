Пояснения — внешние участники из LMS

ДельтаПоле API / условиеПримечание
«N чел.»GET /api/groups → userCountСчёт не меняется: внешние записи — обычные члены группы, импорт сам добавляет их в выбранную при загрузке группу
«из них N внешних»GET /api/groups → externalCount; метка есть только при > 0Сколько членов группы — внешние записи (is_external), включая внешних участников PRD-28, а не только пришедших из выгрузки. Щелчок открывает то же окно участников
Внешняя запись в окне участниковemail = NULL, is_externalОбщая таблица, без отдельного блока. «—» вместо почты и отметка «Внешний», как на экране «Пользователи». Убрать из группы можно как любого участника
Имя внешней записиusers.nameФИО из файла, если обезличивание выключено, иначе «Участник» и первые восемь знаков псевдонима; при совпадении с подписью другой внешней записи подпись новой удлиняется (п. 3.1 плана). Так же участник называется в аналитике
Предупреждение при удалении группыпрохождения из LMS с меткой группы > 0Числа этого объекта: прохождения и загрузки. Удаление снимает метку с прохождений и партий — в аналитике они переходят в «Без группы». Членство внешних записей удаляется вместе с группой, как у всех
Строка без почты в «Пользователях»email = NULL«—» вместо адреса, «Последний вход» пуст: войти такая запись не может. Статус «Активен» — п. 6.1 плана
Меню записи без почтыemail = NULL«Сбросить пароль» погашен как у любого внешнего. «Сделать штатным» погашен: переход отправляет приглашение на почту. «Отправить приглашение» не показан, как у внешних PRD-28. Почту можно задать через «Редактировать» — тогда запись становится обычным внешним участником
