Аннотации состояний

Модал смены варианта на существующей page-row. Триггер — … row-menu → «Сменить вариант». Применим ко всем kind (info / intro / summary / router / questions). Контракт совместимости параметров описан в PRD-1 §4.3.3.

StateНазначениеFR / решение
s-replace-modal Основное: список вариантов того же kind из текущего шаблона. Текущий вариант помечен меткой «Текущий» и disabled. Под списком — warning-блок «Часть настроек не переносится» с перечнем теряемых полей. Совпадающие поля переносятся тихо — отдельного блока «сохранится» нет, чтобы не нагружать модал положительной информацией (пользователь увидит сохранённые значения позже в page-row-expand при редактировании). Контракт совместимости: «имя поля = совместимый тип» — поля сравниваются между вариантами одного kind. PRD-1 §4.3.3
s-replace-empty-diff Спокойный случай: у нового варианта есть все те же поля, что у текущего (имена и совместимые типы). Модал содержит только список вариантов — никаких warning-блоков. Кнопка «Сменить вариант» доступна. Используется, когда варианты структурно симметричны (например, «Минимальный» и «Расширенный» комплекты вопросов). PRD-1 §4.3.3
s-replace-no-fields У нового варианта нет редактируемых полей — содержимое полностью задано шаблоном. Warning-блок «Текущие настройки страницы будут потеряны» содержит перечень текущих значений и пояснение, что после смены страница становится шаблонной. В page-row после смены не отрисовывается chevron — раскрывать нечего. PRD-1 §4.3.3
