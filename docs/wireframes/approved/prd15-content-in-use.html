Тема «Финансовая грамотность» входит в выдачу вопросов опубликованных тестов. Удаление нарушит их работу.

Тест нельзя опубликовать: выдача вопросов невыполнима

При текущем составе тем тест «Аттестация отдела продаж» не сможет собрать вариант для прохождения.

Тема «Переговоры»
  • Выдача вопросов: настроено 10, в теме доступно 7
Тема «Продукты компании»
  • Квота по тегу «тарифы»: нужно 4 вопроса, доступно 2
  • Уровень «Профи» адаптивной выдачи: нужно 5 вопросов, доступно 3
Уменьшите объём выдачи в настройках секций или добавьте вопросы в перечисленные темы, затем повторите публикацию.

Пояснения — покрытие PRD-15 FR-05/FR-06

КодОписание
FR-05Ответ сервера 409 `content_in_use` открывает диалог блокировки: список зависимых опубликованных тестов, по каждому — статус, владелец и причины человеческим языком.
FR-05Формулировки причин по видам: пул меньше объёма выдачи; квота по тегу невыполнима; уровень адаптивной выдачи пустеет; потеря вкладов в шкалы; удаление привязанных страниц; сокращение выдачи «все вопросы темы».
FR-05Автору доступно только «Понятно» + подсказка, как разблокировать. Администратору — «Удалить принудительно» (= повтор запроса с `?force=true`) с warning-баннером последствий; действие журналируется.
FR-05Состояние «Только предупреждения»: black-блокировки нет, но операция затрагивает черновики или drawAll-секции — диалог подтверждения ДО операции. Для этого клиент сначала запрашивает оценку (предпросмотр), затем выполняет операцию; серверу добавляется параметр предпросмотра `?dryRun=true` на DELETE/PUT (оценка уже считается, изменение минимально).
FR-06Ответ 409 `publish_infeasible` при публикации: разбор по темам теста с теми же формулировками; действие «Открыть структуру теста» ведёт в редактор на вкладку Структура.
—Тот же диалог блокировки используется для PUT вопроса (перетегирование/сложность/перенос) и массовых операций; заголовок меняется по операции: «Вопрос нельзя изменить…», «Вопросы нельзя удалить…».
—Ошибка 403 `content_forbidden` (не создатель) диалога не открывает — toast с текстом сервера.
