Acceptance — PRD-3: администрирование шаблонов

СостояниеРаздел PRDПокрывает
s-список / s-пусто§3.2Карточки шаблонов с настоящим превью (assets.preview): имя+идентификатор, тип (встроенный/загруженный), версия, статус (активный/черновик/неактивный/невалидный), проверка (пройдена/предупреждения/не пройдена/не проверялся), использование, действия. Невалидный — «Превью недоступно». Пустой список — подсказка + загрузка.
s-меню-строки§3.2, §5Меню действий карточки: детали, предпросмотр+проверка, обновить, экспорт, деактивировать, удалить (выключено с подсказкой, если используется).
s-загрузка-выбор/обработка§3.1Зона перетаскивания/выбора ZIP, лимит 20 МБ, запрет внешних ссылок; индикатор распаковки и проверки комплектности.
s-загрузка-принят/отклонён/предупреждения§4.1, §4.2Результат комплектности: принят как черновик; отклонён со списком блокирующих ошибок (нет описания / внешняя ссылка / нет файла); принят с предупреждениями.
s-детали§3.3Описание (только чтение), макеты, параметры, журнал проверки, использование.
s-предпросмотр/проверка-идёт/пройдена/не-пройдена§3.4, §4.3, NFR-01/03Живой предпросмотр на демо-данных + проверка работоспособности. Слева — трёхуровневый сворачиваемый список «Раздел → Тип → Вариант отрисовки» (тип может иметь несколько вариантов: «Введение», «Итог» — по 2; тип вопроса «Один вариант» — 2 варианта отрисовки и т.п.); статус проверки на варианте; разделы и типы сворачиваются. Гейт активации.
s-деактивация§5.3, NFR-04Подтверждение + предупреждение о переключении N тестов на «Стандартный» (параметры сохраняются), транзакционно.
s-удаление / s-удаление-нельзя§5.4Удаление загруженного неактивного неиспользуемого шаблона; блокировка с объяснением, если используется/активен.
s-обновление§5.5–5.6Повторная загрузка + отчёт о переносе параметров (сохранены / удалены / требуют значения).
s-экспорт§7Экспорт встроенного/загруженного шаблона в ZIP, валидный как стартовый.

Пояснения — Wireframe

ЭлементПоле API / условиеПримечание
Состояния wireframeshowState(btn, id)Метанавигация переключает только визуальные состояния; не часть продуктового интерфейса.
Список шаблоновGET /api/admin/templatesВключает встроенные и загруженные, все статусы.
ЗагрузкаPOST /api/admin/templatesАрхив с блокирующими ошибками отклоняется и не создаётся; при успехе — черновик.
Проверка/активацияPOST …/smoke-test, PUT …/activateАктивация при validation_json.ok && smoke_test_json.ok (NFR-01).
ДеактивацияPUT …/deactivateКаскад: тесты с этим templateId → «Стандартный», параметры сохраняются (§5.3).
УдалениеDELETE …/:idТолько загруженный, неактивный, не используемый (§5.4).
