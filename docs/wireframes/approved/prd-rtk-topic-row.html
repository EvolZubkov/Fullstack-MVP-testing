Пояснения — строка темы

ЭлементПоле / источникПримечание
Переключатель состоянийshowState(btn, id)Каркас эскиза; в продукте отсутствует
Холстклассы шаблона «Сертификация» и токены DSПравила скопированы из styles/report.css; значения — из разбора референсного PDF
Две колонки строки темыобёртки -main / -asideСлева имя и чип уровня, справа толкование (компетенция) либо полосы подтем (знаниевая тема)
Снято: «N из M (X %)», баллыcountsLabel, pointsFixedLabelРеференс их не содержит; в документе они не гейтятся надписями topic.correct / topic.points
Снято: полоса исхода над строкойtb-report__topic-stripeДублировала чип и дробила лист; строки разделяет волосяная линия, цвет исхода несёт чип
Чип уровняtopic.verdict.passed / failed (PRD-49)Белый, с рамкой и цветной точкой. Слова «целевой уровень» / «начальный уровень» задаёт автор надписями
Счётчик блокаgroup.counter, формат {passed}/{total}Считает темы с вынесенным вердиктом (PRD-50 FR-26)
Полоса подтемыbarPercent, passClassНе меняется: цвет по вердикту, дорожка светло-серая, значение печатается
Подпись «Нужно N %»requiredLabelПриходит в контекст вместе со значением, но макет её не печатает: порог производный от темы и повторялся бы под каждой подтемой
Толкование подтемпризнак в tests.breakdown_display_jsonПо умолчанию скрыто. Включённый показ разворачивает сетку в список: текст стоит под своей полосой, название не повторяется
Метрики колонокколонка 76 px, полоса 5 pxСняты с референса (PRD-51 §10.3); шаг сжат до 26 px — наш лист вдвое уже оригинального
