Acceptance — FR-30 покрытие

КодОписание
FR-30Удаление теста требует ввода точного названия (case-sensitive) для подтверждения; кнопка «Удалить навсегда» disabled до точного совпадения.
FR-30Текст предупреждения inline содержит название теста; warning описывает безвозвратность и удаление назначений / результатов попыток.
FR-30Кнопка подтверждения — destructive (красная) по DS (`ou-btn--destructive`).
—Состояния: s-empty (input пустой), s-mismatch (введено неточно — input error, сообщение под полем), s-match (точное совпадение — input success, кнопка enabled).
—После удаления — redirect на список тестов; Toast «Тест удалён» (action error → toast, не state-level).
