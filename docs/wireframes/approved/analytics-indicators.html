Пояснения — показатели в аналитике теста

ЭлементПоле API / условиеПримечание
Вкладка «Шкалы и показатели»hasScales || hasIndicatorsПрежняя вкладка «Шкалы», id в адресе прежний (scales) — сохранённые ссылки не ломаются. Порядок — показатели, затем шкалы, как в деталях попытки. Пустой блок не выводится (FR-21c)
Фильтр экранаусловия FilterBar в запросе вкладкиИсточник, группа, период действуют и на показатели, и на шкалы (FR-21f). Раньше запрос шкал их не передавал
Значение показателявеб — result_json.resultVariables; телеметрия и импорт — variables_jsonТолько сохранённое значение, без пересчёта по ответам (FR-21e, решение владельца 2026-10-07). Строки из пакета и выгрузки приводятся по типу показателя
«у N не передано»прохождения выборки без значения этого показателяНе входят в n и в доли. Выводится, только если N > 0
Показатель без значений вовсеn = 0Название приглушено, вместо полосы — «не передано ни в одном из N прохождений». Ноль и пустая полоса запрещены (FR-27)
Числовой с уровнямиtype = number, есть полосы толкованияСреднее «X из максимума» в строке заголовка, под ней строка на уровень: ProgressBar с подписью и долей, как «Профиль по шкалам» — доли сравниваются длиной полос (владелец 2026-10-08: в составной полосе сравнить нельзя). Уровни без прохождений не выводятся
Числовой без уровнейtype = number, полос нет; histogramКомпактная гистограмма (половина ширины карточки, высота 120 px — столбики узкие): доля прохождений по 10 равным интервалам домена (владелец 2026-10-08: одно среднее распределения не показывает). Целые значения — целые границы интервалов («0–2»); если различных значений не больше 10 — столбик на значение. Без домена интервалы строятся по наименьшему и наибольшему значению всех прохождений теста, чтобы фильтр и срезы не сдвигали границы. Столбики акцентом (FR-21b). В сравнении срезов — таблица долей по тем же интервалам, вид как у уровней; интервал, пустой во всех срезах, не выводится
Строковый и логическийtype = string | booleanСтрока на исход, как у уровней (ProgressBar с подписью и долей), по убыванию доли; при равенстве — порядок исходов в толковании (владелец 2026-10-08). Уровни числового показателя — в своём порядке, от низкого к высокому. Сопоставление — findOutcome, как в итогах участника; исходы с одинаковой подписью сводятся в одну строку; без исходов — строки по самим значениям, ключи шкал печатаются названиями шкал. «Прочее» — последней строкой. Исходы без прохождений не выводятся. Цвета исходов (тон автора, иначе категориальная палитра) действуют в таблицах сравнения срезов
Скрытый от участника показательlearner_visibility = hiddenВ аналитике виден: автор видит его всегда
Сравнение срезов: «Показатели»slices[].indicatorsНад блоком «Шкалы». Числовые — средние в одной таблице, «Разница» при двух срезах в единицах показателя. Уровни числового и исходы строкового и логического — таблица на показатель, как уровни шкалы. Третий пункт переключателя метрик переименован: «Ответы и шкалы» → «Ответы, шкалы и показатели» (владелец 2026-10-07)
Выгрузки (вне холста)Excel аналитики, протокол попыткиFR-21h: лист «Прохождения» книги одного теста — колонки шкал и показателей у всех источников; лист «Измерения» — строки всех источников, «Уровень» показателя — метка уровня или исхода; протокол — лист «Показатели»: Ключ, Название, Значение, Уровень / исход
