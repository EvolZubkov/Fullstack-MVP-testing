ЭлементПоле / условиеПримечание
Вкладка «Оценка»новая вкладка редактора теста (между «Структура» и «Шкалы»)Оценка — ось правильности (балл, цена ответа) + сложность для адаптива. Шкалы/Показатели — оси измерения и результата, не смешиваются
Балл за вопрос по умолчанию (тест)tests.default_question_points, пусто = системное умолчание 1FR-31. Действует на вопросы без переопределения и без балла секции
Балл по умолчанию в секцииtest_sections.default_points, пусто = как у тестаFR-31. Цепочка: переопределение → секция → тест → 1
Таблица вопросов секцииполный пул темы (не только выдача): Балл / Цена ответа / Сложность — действующие значенияПризнак «настроено в тесте» — полоска слева у строки с переопределением (быстрый скан, конвенция VS Code) + мягкая акцентная заливка КАЖДОЙ переопределённой ячейки с подсказкой при наведении (видно, какой именно параметр настроен); унаследованное — без пометок. У несохранённого переопределения дополнительно горит точка несохранённых изменений вкладки. Дублирующий признак — кнопка «Сбросить» только у строк с настройкой
«Настройка устарела»pinned_content_hash ≠ contentHash вопросаFR-30. Состав вариантов изменился после настройки; оценка продолжает действовать. Действия: «Подтвердить актуальность» (перепривязка к новому хэшу) / «Сбросить настройку» (удалить переопределение)
Сбросить настройку оценкииконка-кнопка в строке; убирает переопределение из драфта (persist на «Сохранить»)Вопрос возвращается к цепочке умолчаний. Кнопка есть только у строк с переопределением
Модал «Оценка вопроса в тесте»балл + цена ответа + сложность одного вопроса в этом тестеFR-35. Конструктор ступеней/весов перенесён из карточки вопроса (prd10) без изменений механики. Поля и сегмент инициализируются действующими значениями (из вопроса или цепочки умолчаний); признак настройки в форме — заполненное поле (пустое с плейсхолдером = наследуется), любое изменение = переопределение
«Сбросить настройку» в модалеудаляет переопределение целиком (балл, цена, сложность)Вопрос возвращается к действующим значениям без настройки в тесте; то же действие, что иконка «Сбросить» в строке таблицы
Сложность в этом тестеtest_question_scoring.difficulty, пусто = базоваяFR-34. Адаптивная выдача и проверки выполнимости используют действующую сложность
Карточка вопросаполя «Балл» и «Цена ответа» удалены; «Сложность (базовая)» и «Теги» остаютсяFR-35. Инфо-баннер ведёт во вкладку «Оценка». Конструктор градуировки из карточки удаляется
Переходный период (до T-40)колонки questions.points/scoring_json ещё живыЗначения из банка продолжают действовать, переопределения работают сразу. Умолчания секции/теста начнут действовать после удаления колонок (T-40, отдельный релиз) — до этого значение из банка имеет приоритет. РЕШЕНО (согласование 2026-06-12): поля умолчаний показываются в UI сразу
maxPoints секцийΣ действующих баллов вопросовАбсолютные пороги в «Настройках» капятся по действующим значениям (уже на сервере)
Сохранение переопределений«Применить»/«Сбросить» правят драфт; persist на едином «Сохранить», «Закрыть» откатываетПереопределения — часть драфта, как умолчания (не пишутся на сервер на клик). На «Сохранить» редактор сверяет их со снапшотом и шлёт PUT/DELETE question-scoring; «Подтвердить актуальность» — повторное «Применить» (re-pin contentHash)
