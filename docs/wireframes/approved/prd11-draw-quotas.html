Пояснения — Wireframe

ЭлементПоле / условиеПримечание
Переключатель состоянийshowState(btn, id), тоглы темы/плотности/аннотацийКаркас эскиза; в продукте отсутствует
Поверхностьстрока темы (tb-topic-row) во вкладке «Структура»Реальный компонент: topics-structure-section.tsx (ui-kit). Шапка (название/кол-во/обязательная/удалить) и тело (Вопросов в тест + Обратная связь) — существующие
Свич «Квоты по подтемам»наличие draw_blueprint_jsonВыкл = равномерная выдача (FR-02). Вкл → инлайн-блок (без модалки — конфиг мелкий, в отличие от «Обратной связи»)
Квота — ось доставкиtest_sections.draw_blueprint_json (§4)Уточняет «Вопросов в тест» (draw_count). Ортогонально «Цене ответа» (PRD-10) и расчёту (FR-08)
Подтема = тегquestions.tagsSelect показывает РЕАЛЬНЫЕ теги вопросов этой темы (не свободный ввод); отдельной сущности/иерархии тем нет (FR-07)
Строка квотыstrata[]: {tag, count, mode}Тег — Select реальных тегов, count — NumberInput, режим — SegmentedControl В КАЖДОЙ строке
Режим (на тег)mode: exact / min — свойство КАЖДОГО тега, не темы«Ровно» — РОВНО count; «Не менее» — минимум, остаток может добрать ещё этого тега. Дефолт «Ровно». Тогл «Общий/По тегам» убран (упрощено 2026-06-04)
Остаток выборкиdraw_count − Σ countСлучайно из остальных вопросов; дедуп общий used (вопрос с несколькими тегами — один раз, FR-04)
Сумма квотΣ count <= draw_countИначе — ошибка валидации, сохранение блокируется (FR-05)
Нехватка по тегудоступно < countНЕблокирующий warning (баннер + колонка «Доступно» + тег); выдаётся сколько есть (FR-06)
