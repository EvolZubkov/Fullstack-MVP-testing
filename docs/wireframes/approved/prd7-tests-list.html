Acceptance -- PRD-7 покрытие

КодОписание
—Структура списка: Explorer-модель. Корень "Все тесты" → папки с chevron (expand/collapse, aria-level="2") → тесты внутри папки с отступом и indent-guide (aria-level="3"). Тесты без папки лежат в корне на уровне aria-level="2" рядом с папками -- без псевдопапки "Без папки".
—Папка свёрнута: chevron без rotate, дочерние тесты не рендерятся. Папка раскрыта: chevron повёрнут 90°, тесты видны с indent-line.
—Поиск: переключает дерево в плоский список-выборку (role="list"). Все папки раскрыты принудительно. У каждого результата показывается breadcrumb-путь (папка / тест). Banner с role="status" aria-live="polite". Кнопка "Сбросить" возвращает к дереву.
—Фильтры -- отдельный PRD (placeholder в toolbar, без реализации в текущем scope).
FR-30Удаление только из dropdown, кнопка "Удалить тест..." ведёт к confirmation dialog.
FR-31"Архивировать" в dropdown; подпункт «Архив» в сайдбаре ведёт к prd7-tests-archive.html.
§1Видимые кнопки на каждой карточке теста (при наведении): Редактировать (#i-pencil), Назначить (#i-users2), Аналитика (#i-chart), Ещё (#i-more). Экспорт SCORM перенесён в dropdown.
§1Dropdown «...» содержит: Редактировать / Экспорт SCORM / separator / [Опубликовать | Снять с публикации] (контекстно по статусу) / separator / Переместить в папку / Архивировать / separator / Удалить тест...
FR-08 BRDInline actions (редактировать, назначить, аналитика) visible on hover; dropdown через «...» содержит Экспорт SCORM и уникальные операции.
—Dropdown папки: Переименовать / separator / Удалить папку... (всегда активна — оба варианта доступны вне зависимости от наличия тестов).
—Удаление папки — два варианта (реф: PowerPoint «Удалить раздел»): (A) Только папку — тесты перемещаются в выбранное место (Корень или другую папку); (B) Папку и все тесты — требует ввода точного имени папки в поле подтверждения, кнопка активируется только при совпадении. Кнопка подтверждения в обоих вариантах — destructive (UX-конвенция: слово «Удалить» → красный цвет всегда).
—Состояния: default (дерево), collapsed (папка свёрнута), search (плоская выборка), Меню: Черновик (dropdown с «Опубликовать»), Меню: Опубликован (dropdown с «Снять с публикации»), Меню папки, Удалить: только папку, Удалить: с тестами, Предпросмотр, Lazy load, Загрузка (skeleton), Пусто, FAB: выбор папки, FAB: ограниченный, FAB: раскрыт (speed-dial).
FABSpeed-dial FAB (d=56px, pill, accent, z-index: 20, position: absolute bottom/right space-6). Заменяет кнопки «Новый тест» и «Папка» в шапке. Виден всегда (desktop + mobile). Клик открывает speed-dial с двумя sub-actions: «Новый тест» и «Новая папка» — кнопки d=44px над FAB. FAB поворачивается на 45° (→ ×-иконка закрытия). Backdrop модала перекрывает FAB через z-index: 50.
FABНеограниченный пользователь: клик FAB → модал «Создать тест» со списком всех папок + опция «Корень (без папки)». Выбранная строка подсвечивается accent-soft. Кнопка «Создать тест» запускает создание в выбранной папке.
FAB (ограниченный)Пользователь с ограниченными правами: FAB → модал только с разрешёнными папками, info-баннер «Вы можете создавать тесты только в папках, доступных вашей роли.» Опция «Корень» и недоступные папки не показываются.
