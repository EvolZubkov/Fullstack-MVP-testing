Правила

ЭлементДанныеПоведение
Правило тестаtests.question_order«Фиксированный порядок» / «Перемешивание» (умолчание) / «Полное перемешивание» (FR-16)
Место правила—Вкладка «Состав», НАД списком тем: сначала общее правило, под ним темы, которые его наследуют
Режим с разбивкой по темамflowPolicy.mode«Полное перемешивание» в списке отсутствует; при переходе теста в такой режим сохранённое значение переписывается в «Перемешивание» (FR-17)
Правило темыtest_sections.question_order (nullable)Умолчание — «Как в тесте» (NULL). Явное значение = переопределение (FR-18)
Хвост строки темы—Показывает ДЕЙСТВУЮЩИЙ порядок, иначе «Как в тесте» само по себе ничего не сообщает
Сброс «как в тесте»—Пиктограмма появляется только при переопределении и сама служит признаком переопределения — отдельного бейджа «изменено» нет
Полное перемешивание—Вопросы всех тем идут одним потоком (FR-19); тема с фиксированным порядком выдаётся неразрывным блоком в случайном месте (FR-20)
Режим вариантовform_set_jsonПереопределение действует, но источник порядка — список варианта (FR-07)
Отборdraw_count, квоты PRD-11Не меняется: правило сортирует уже отобранное (FR-06)

Дельта к существующему UI

ЧтоГдеПочему так
Строка tb-test-order-rowвкладка «Состав», topics-structure-section.tsxПравила скопированы с tb-draw-count-row: та же анатомия «подпись + контрол + приглушённый хвост»
Свитч темы становится Selectтело темы, tb-question-order-rowПозиций стало три. Замена предусмотрена утверждённым эскизом PRD-30: «появление третьей позиции заменит свитч на Select без миграции». Класс строки не меняется, меняется начинка
Подпись строки темы—«Случайный порядок вопросов» описывала двухпозиционный свитч; у списка из трёх значений подпись — «Порядок вопросов». НА СОГЛАСОВАНИЕ
«Перемешивание», а не «Перемешивание внутри темы»—В режимах с разбивкой уточнение избыточно — границу темы задаёт сам режим; нужно оно только в сплошном, где значение отличается от «Полного перемешивания». Уточнение — свойство состояния, поэтому живёт в хвосте строки, а подпись значения одна во всех режимах
Пиктограмма сбросарядом с Select темыТот же IconButton + RotateCcw, что в «Оформлении» (сброс цвета к шаблону) и в «Оценке» (сброс настройки вопроса) — приём в проекте уже принят
Своих цветов и размеров нет—Дельта состоит из одного класса раскладки на токенах ДС
