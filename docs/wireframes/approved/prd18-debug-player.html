Структура — по сценарию: «по темам» — иерархия (тема с резюме раскрывается в свои вопросы); flat — резюме по темам + единый раскрывающийся раздел «Вопросы» в порядке выдачи. Тем в тесте может быть сколько угодно, у каждой — своё число вариантов; темы НЕ в режиме вариантов (тег-квоты / случайная выборка / все вопросы) селекта не имеют. Селекты активны ТОЛЬКО до старта прогона (все варианты фиксируются в момент старта): после «Начать» они disabled; «Сброс» возвращает старт-экран и снова делает выбор доступным. Применяется НА СТАРТЕ прогона; смена значения перезапускает стейдж (перевыдача из уже отгруженного банка форм — без пересборки пакета).
