Acceptance — FR-31 покрытие

КодОписание
FR-31Архивированные тесты не отображаются в основном списке. Архив доступен через подпункт «Архив» в сайдбаре раздела Тесты.
FR-31Восстановление через icon-кнопку с tooltip и confirmation dialog; тест переводится в статус «Черновик».
FR-31Edge case orphan: если папка тест была архивирован в удалённую папку — в диалоге показывается предупреждение; тест восстанавливается в корень.
FR-31Удаление навсегда (permanent delete) через icon-кнопку с confirmation dialog. Данные попыток также удаляются.

—Состояние «Архив пуст» с empty-state текстом.
