КодОписание
FR-31Архивированные тесты не отображаются в основном списке (prd7-tests-list.html). Архив доступен через отдельный раздел ("Архив тестов" в header страницы тестов).
FR-31Восстановление через icon-кнопку с хинтом и confirmation dialog; тест переводится в статус "Черновик".
FR-31 edge caseЕсли папка, из которой тест был архивирован, удалена: в диалоге подтверждения показывается предупреждение; тест восстанавливается в корень списка тестов.
—Архивированные тесты недоступны для назначения (кнопки назначения отсутствуют).
—Таблица содержит колонки: Статус, Режим, Сценарий, Тем, Вопросов, Архивирован, Назначений.
—Панель предпросмотра по аналогии с prd7-tests-list.html — toggle-кнопка в последней колонке заголовка.
—Состояние "Архив пуст" с empty state.
