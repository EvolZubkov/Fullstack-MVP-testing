Пояснения — Wireframe

ЭлементПоле API / условиеПримечание
Строка под именемusers.unit · users.positionРешение владельца 2026-09-28: вместо двух колонок. На живой странице с боковым меню они не поместились в 1440 px — DS-таблица обрезает лишнее, и «Создан» с меню строки уходили за край. Пустые части опускаются; нет ни того, ни другого — строки нет. Организация в списке не показывается: она в фильтре и в карточке, на большинстве инсталляций одна на всех
Поле поискакласс tb-users-searchДержит минимальную ширину (--tb-input-w-md): иначе семь элементов ряда сжимали его до «Поиск по email», а по эскизу поиск занимает первую строку
Фильтры оргструктурызначения — различные значения профилей в спискеСравнение без учёта регистра и лишних пробелов (план, Р-4). Пункт «Не указано» отбирает пустые. Отбор клиентский, как у остальных фильтров списка. Фильтры с поиском — у подразделений бывают сотни
Поля «Организация» / «Подразделение» / «Должность»Combobox одиночный; справочник GET /api/users/org-valuesВыбор из существующих значений или «+ Создать «…»»; свободного ввода нет (план, Р-3). Образец — поле «Последовательность» PRD-22. В подписи варианта — сколько раз значение встречается в профилях и в прохождениях: вариант «только в прохождениях» — написание, которое уже пришло из LMS
Порядок полей—Оргполя идут сразу за именем: они есть у всех. Ключи связывания — в конце формы, как уже стоит «Внешний ключ»: они нужны единицам
«Идентификатор в LMS»users.lms_learner_idBR-54-31: по нему телеметрия и импорт связывают прохождение с человеком. Уникален (план, Р-6): чужое значение — ответ 409, ошибка у поля называет владельца
«Внешний ключ» в окне правкиusers.external_keyПоле уже было; сейчас окно не отправляет его на сервер, и правка теряется (план, задача 0)
Внешний участникusers.is_externalОргполя у внешнего участника доступны: подрядчик тоже работает в каком-то подразделении своей организации, и разрез «внешние по организациям» — законный вопрос
Предпросмотр загрузкиколонки шаблона organization, unit, position, lms_learner_idЗаголовки читаются и по-русски. Оргполя — одна колонка в две строки (подразделение; должность · организация), ключи — одна колонка «Ключи связывания» (идентификатор в LMS, внешний ключ): иначе колонок десять и «Статус» с «Действием» уходят за край окна. У дубля действие «Обновить» перезаписывает оргполя так же, как имя. Занятый идентификатор в LMS — ошибка строки, причина во всплывающей подсказке, как у остальных ошибок
Описание окна загрузкишаг «upload»Строка «Необязательные: name, role» устарела ещё до этой работы; перечень колонок в ней заменяется полным: name, role, group, external_key, organization, unit, position, lms_learner_id
Приглашение участников при назначении тесташаблон email, name → плюс оргполяBR-54-29. Вкладка «Списком» не меняет раскладку: колонки оргполей в предпросмотре появляются, только если они есть в файле. Существующему человеку заполняются лишь пустые поля — как сегодня с именем
