Пояснения — Wireframe

ЭлементПоле API / условиеПримечание
Текст вариантаquestions.option_feedback_json: массив строк или null, позиция = позиция варианта в dataJson.optionsТолько тип «Один ответ». У остальных типов переключателя нет. Пустая строка = текста нет.
Какой текст видит ученикfeedbackTextFor(q, isCorrect, chosenIndex)Текст выбранного варианта, если он задан; иначе обратная связь вопроса по текущему правилу (общая или ветка «верно / неверно»). Заголовок и тон плашки не меняются. Экран ученика внешне не меняется, поэтому его в эскизе нет.
Переключатель «Переопределить обратную связь»включён, если у варианта есть текстВключение открывает поле под переключателем. Выключение прячет поле; при сохранении текст выключенного варианта не хранится.
Перестановка и удаление вариантамассив переставляется вместе с optionsТекст едет за своим вариантом при перетаскивании; удаление варианта удаляет и его текст. Пустые варианты, отброшенные при сохранении, уносят свои тексты.
Смена типа вопросапри сохранении не-«Один ответ» поле пишется nullКак уже сейчас с текстом общей обратной связи в условном режиме: неприменимое не хранится.
Реестр: строки вариантовподпись — текст варианта в кавычкахКаждый вариант с текстом — отдельная подстрока под своим вопросом: в колонке «Вопрос» значок CornerDownRight и текст варианта, в «Режиме» — «Вариант», в «Тексте» — текст варианта. Между вопросом и подстроками линии нет (модификаторы tb-qfeedback-row--has-sub, tb-qfeedback-row--sub). Счётчик «у N задана обратная связь» учитывает и тексты вариантов. Реестр остаётся только для чтения.
