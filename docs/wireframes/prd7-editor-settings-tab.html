КодОписание
FR-43Вкладка "Настройки" имеет двухуровневую навигацию: side nav (220-260px) на >=960px и <select> на <960px. Семь секций в порядке: Основное, Режим и сценарий, Правила прохождения, Ограничения, Обратная связь, Интеграция, Адаптивность.
FR-43 / §3.1Основное: Название (обязательное), Описание, Статус (Черновик / Опубликован / В архиве) с подсказкой о том, что смена статуса происходит вне редактора.
FR-43 / §3.2-3.3Режим и сценарий: segmented control для tests.mode (Стандартный / Адаптивный), select для flowMode с четырьмя значениями, router-specific поля (completionPolicy, sectionUnlockRules) для router_by_topics. Inline warning без кнопок Применить/Отмена.
FR-43 / §3.4Правила прохождения: overall pass rule, passDecisionPolicy с четырьмя вариантами и заметкой о рекомендуемых умолчаниях, таблица тем с topicPassRule.source (inherit_overall / custom / none), toggle required.
FR-43 / §3.5Ограничения: лимит времени теста, раздел "Лимит времени темы" с topicTimeLimit.source, таблица индивидуальных лимитов, двойной таймер-preview, max_attempts, show_correct_answers.
FR-35 / §3.6Обратная связь: карточка "Общая обратная связь теста" (tests.feedback, test_feedback_links, feedback_assets scope=test), карточка-подсказка для перехода к теме обратной связи в Составе.
FR-35 / §3.7Интеграция: Webhook URL (tests.webhook_url) и toggle telemetry_enabled, независимые друг от друга.
FR-36 / §3.8Адаптивность: доступна только при tests.mode = adaptive. Показывает: read-only chip режима, toggle show_difficulty_level, карточку adaptive_settings_json, таблицу тем (enabled, failure_feedback, кнопка Уровни), раскрытую панель уровней с полями level_index, level_name, min_difficulty, max_difficulty, questions_count, pass_threshold, pass_threshold_type, feedback, ссылки, документы PDF. Справочный график распределения сложности. Без IRT / SE / "критерия завершения".
