Баннер-предупреждение о таймере — СИСТЕМНЫЙ: показывается сам, когда у раздела есть лимит времени, со стандартным текстом и длительностью раздела. Раньше эту фразу автор дописывал в инструкцию раздела вручную; её оттуда можно убрать. Инструкция автора остаётся карточкой, как сейчас.

Метка «Обязательная тема» — только при политиках «Общий результат и обязательные темы» и «Все обязательные темы»: при остальных обязательность не влияет на вердикт.

Для шаблонов: новые необязательные поля sectionIntro.passCondition (готовая строка), sectionIntro.isRequired и sectionIntro.timerWarning (готовая строка, есть только при лимите времени раздела); шаблон без них показывает вводную как раньше. Оба хоста — пакет и веб — строят их одним общим построителем.
