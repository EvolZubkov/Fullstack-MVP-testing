Пояснения — Wireframe

Элемент Поле API / условие Примечание
Состояния wireframe showState(btn, stateId) Метанавигация переключает только визуальные состояния и не является частью продуктового UI.

DS Mapping

Заполняется после gate этапа 3, до старта frontend (этап 3.5). Строка с «custom» в колонке DS-компонент является блокером.

Элемент wireframe DS-компонент Используемые токены Примечания
Метанавигация состояний Wireframe utility --ou-space-*, --ou-border-*, --ou-accent-* Не мигрируется в продуктовый UI.
