КодОписание
—Структура linear_flat: вопросы из всех тем перемешиваются в единую последовательность. Каждая тема имеет поле "показывать X из N".
—Таблица пула: колонки Тема, Кол-во (draw input), Доля (weight bar). Итоговая строка показывает сумму.
—Схема воспроизведения: предпросмотр последовательности шагов для слушателя (стартовая страница, основной блок, результат).
—Ошибка нулевого draw: поле с border-color: destructive, inline-ошибка "Минимум 1", индикатор ошибки на вкладке, кнопка "Сохранить" disabled.
NFR-21draw-inputs имеют aria-label; поле с ошибкой имеет aria-invalid; error-div имеет role="alert".
