Аннотации состояний

Уникальные для router_by_topics состояния. Общие паттерны (s-mapping модал, s-add-step1 модал, s-page-preview, dirty / sanitize, s-delete, s-dnd) — см. prd7-structure-linear-by-topics.html. Generic-состояния drawer'а (s-loading, s-error, s-saved) — см. approved/prd7-editor-drawer.html.

StateНазначениеFR / решение
s-main Основное состояние router-режима: системная router-row внутри теста + темы как ветки под router-row через tree-connectors (тонкие DS-линии --ou-border-soft). У каждой темы — своя questions-row с локальным per-topic variant'ом (Тема 1 — «Минимальный», Тема 3 — «Расширенный»). Зоны «До теста» / «После теста» как в linear_flat. PRD-7 §2.3b, PRD-8 FR-02, FR-06a-c
s-main-multi-variant В шаблоне N > 1 вариант нужного kind: возле бейджа системной row — caption-метка «Доступно N вариантов» (тонкая, --ou-fg-muted, italic). Смена варианта — через … row-menu → «Сменить вариант» (модал s-replace-variant, см. prd7-variant-replace.html). PRD-1 §4.3.2
s-main-fallback В шаблоне теста 0 вариантов нужного kind: система применяет fallback на вариант того же kind из встроенного стандартного шаблона. Возле бейджа — warning-метка «Из стандартного шаблона» с --ou-warning-soft фоном. PRD-1 §4.3.2 (fallback)
s-empty-topics Router-row есть (создаётся тихо при выборе режима), но в составе теста не выбрано ни одной темы — на месте веток tree-branches показывается ou-empty с CTA на вкладку «Состав». Empty-state для самой router-row отсутствует: variant всегда привязан тихой логикой или fallback'ом. PRD-7 §2.3b empty-states
s-mode-change Смена flowMode с router_by_topics на linear_*: warning-banner + раскрываемый callout с перечислением преобразований. Ключевой пункт: «Маршрутизатор будет удалён» — страница kind: router удаляется молча без диалога s-mapping, параметры маршрутизатора теряются. Локальные variant'ы questions-row сохраняются. Footer — стандартный dirty-triplet. На табе «Структура» — .status-dot.dirty. FR-25a, FR-25c
s-validation Незаполненные required: true поля в schema варианта (PRD-1 §4.3.6). Поведение: page-row--warn модификатор (warning-цвет заголовка + границы), validation-banner в page-row-expand со списком конкретных полей, на табе «Структура» — .status-dot--error (агрегированный error-индикатор согласно FR-25b / NFR-21), кнопка «Сохранить» disabled с tooltip'ом. Серверный API возвращает структурированную ошибку при попытке сохранения. PRD-1 §4.3.6, FR-25b, NFR-21
s-row-menu-open Иллюстрирует открытый … row-menu (.row-menu) для системной router-row. Состав меню для системных kind (router / summary / intro / questions): «Сменить вариант…» (открывает модал prd7-variant-replace.html), «Предпросмотр», разделитель, «Удалить» — disabled с tooltip «Системную страницу нельзя удалить». Для пользовательских info-row пункт «Удалить» активен (демонстрируется в секции «После теста» — info-row без `--system` модификатора получает полный набор действий, включая destructive «Удалить»). В финальной реализации dropdown управляется JS, позиционирование через position: absolute от .page-actions. PRD-1 §4.3.3
