Acceptance -- PRD-7 покрытие

КодОписание
§5.1Вкладка Структура в режиме router_by_topics использует router-page-centric макет: блок "Страница-маршрутизатор" с карточками разделов, прикреплёнными к нему. НЕ используется линейный flow-chart Старт → Роутер → Секции → Итог.
§5.1 / §3.3Логика роутера (completionPolicy, sectionUnlockRules) отображается только как read-only индикаторы со ссылкой "Изменить в Настройках → Режим и сценарий". Не редактируется в Структуре.
§5Кнопка "Добавить секцию" отсутствует. Список разделов формируется в Составе. Показывается информационная заметка об этом.
§5draw_count и порог прохождения в карточке раздела — read-only chips со ссылкой "Перейти к Составу" / ссылкой на Настройки. Не редактируется в Структуре.
§5Каждая карточка раздела показывает: название темы, обязательный/опциональный badge, количество вопросов (read-only), порог (read-only), слоты для страниц до/после блока вопросов (content_page + "Добавить страницу"), то что увидит слушатель на маршрутизаторе после завершения (preview states: Не начат / В процессе / Пройден / Не пройден / Заблокирован).
§5.1Блок "Итоговый результат" показывается в заблокированном состоянии до выполнения completionPolicy.
—Empty state: Маршрутизатор пустой с CTA "Перейти к Составу". Кнопка "Сохранить" disabled.
NFR-21Блок роутера: role="region" + aria-label; карточки: role="listitem"; read-only режим: чипы без интерактивных элементов управления.
