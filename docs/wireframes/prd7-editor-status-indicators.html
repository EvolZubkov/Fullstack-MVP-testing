Acceptance — PRD-7 покрытие

КодОписание
FR-25bАгрегированные индикаторы dirty/warning/error на табах Drawer; локальные индикаторы на секциях внутри вкладок. Каждый уровень независим: таб может быть dirty, а отдельная секция — error.
NFR-21Все индикаторы статуса передают состояние не только цветом: каждый таб/секция имеет aria-label с текстовым описанием; иконки aria-hidden="true"; поля с ошибками имеют aria-invalid и aria-describedby.
—Inline-валидация под полем: красный текст + иконка (error); warning-блок с жёлтым фоном (предупреждение).
—Состояния секций: clean, dirty (синяя рамка), warning (жёлтая рамка), error (красная рамка) — отличаются border-color и background header.
