prd7 — Status Indicators:
Индикаторы состояния
Все индикаторы сочетают цвет + текст/иконку + aria-label для доступности. Цвет никогда не является единственным носителем информации (NFR-21).
1. Индикаторы на вкладках Drawer
Контент вкладки (placeholder)
Точки: синяя = dirty (изменено), жёлтая = warning (не блокирует сохранение), красная = error (блокирует). Каждая вкладка имеет aria-label с описанием статуса.
2. Индикаторы на секциях внутри вкладки
Основные настройки Сохранено
Название
Правила прохождения Изменено
Порог прохождения (%)
Адаптивные настройки Предупреждение
Переключение в режим "standard" скрывает adaptive-настройки. Данные сохранены, но не будут применены.
Основные настройки Ошибка
Название *
Поле обязательно для заполнения
3. Легенда состояний
Чисто
Нет изменений, нет проблем
Изменено (dirty)
Есть несохранённые изменения
Предупреждение
Не блокирует сохранение
Ошибка
Блокирует кнопку “Сохранить”
Сохранено
Успешно записано
