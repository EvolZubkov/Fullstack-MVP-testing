Пояснения — Wireframe

ЭлементПоле API / условиеПримечание
Абзац над баннером — Текст утверждённого эскиза prd7. В текущей реализации окна его нет — возвращается вместе с баннером.
Баннер: заголовок webAttempts + lmsAttempts из GET /api/tests/:id/delete-impact Показывается, только если сумма больше нуля. Считаются все прохождения, и завершённые, и брошенные: удаляются все.
Баннер: строка про LMS lmsAttempts, importBatches, packages Только при lmsAttempts > 0 или packages > 0. Части «в том числе N загруженные выгрузки» и «Выгруженные пакеты (N)…» выводятся, только если их число больше нуля. Состояние «Только в сервисе» — баннер с одним заголовком.
«Перенести в архив» PATCH /api/tests/:id/status { status: "archived" } То же действие, что «Архивировать» в меню теста: окно закрывается, тест уходит в архив, данные сохраняются. Показывается, только если у пользователя есть право архивировать (tests.publish), — удаление требует другого права.
Пока числа загружаются запрос в полёте Баннера нет, окно работает как в утверждённом эскизе; кнопка «Удалить навсегда» по-прежнему ждёт только совпадения названия. Ошибка запроса — баннера нет.
Участники, заведённые загрузками — Удаляются вместе с загрузкой, если больше нигде не заняты (правило отката BR-54-43). В баннере не считаются: число зависит от других тестов и до удаления не вычисляется дёшево.
