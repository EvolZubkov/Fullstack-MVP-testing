# Картинки из референса «Сертификационный тест для руководителей»

Извлечены 2026-10-16 из проекта Articulate Storyline
[`RTK_Test_commits_last.story`](../RTK_Test_commits_last.story). Это ZIP-архив: исходные файлы
лежат в нём в `story/media/` под служебными именами. Здесь они разложены по экранам и
переименованы, у каждого файла указано исходное имя.

## Титульный слайд — `title/`

| Файл | Размер | Исходник | Что это |
| --- | --- | --- | --- |
| `mountain-flag.png` | 879×786, прозрачный фон | `R5xQMQcPKK4x.svg`, `R6A7VA4p3LIt.svg` | Гора с оранжевым флагом — иллюстрация титульного слайда |
| `title-slide-thumbnail.jpg` | миниатюра | `R6Mnyfb1ov6w.jpg` | Вид слайда целиком, для сверки |

Storyline хранил иллюстрацию в двух SVG-обёртках с одним и тем же растром внутри.
`mountain-flag.png` — этот растр без изменений, лучшее качество, какое есть в референсе.

На слайде иллюстрация составная: одна SVG показывает картинку целиком — большая гора с флагом,
вторая только нижнюю её часть — меньшая гора без флага слева. Здесь лежит одиночная гора.

## Меню разделов (хаб) — `router-hub/`

В референсе хаб нарисован ОДНОЙ фоновой картинкой: заголовки карточек, иллюстрации, плашки
счётчиков и разделители впечатаны в фон, поверх лежат только поля с числами и кнопки.
Поэтому иллюстрации и карточки ниже — вырезки из фона, а не самостоятельные файлы.

У иллюстраций карточек фон НЕ прозрачный: при вырезке вокруг рисунка остаётся цвет карточки
(`#FFFAFA`). Для макета «Меню карточек с картинками» лучше готовить файлы с прозрачным фоном —
на тёмной теме непрозрачный фон виден светлым квадратом.
