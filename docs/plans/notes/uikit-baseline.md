# Базлайн пакета до вендоринга DS

Замер выполнен командой `npm run scorm:template` (шаблон `default`) до начала
ревизии на ui-kit. Служит опорой для оценки прироста веса после вендоринга DS и
шрифта (фаза 1) и для проверки, что DS реально попадает в пакет.

Дата замера: 2026-07-26.

| Показатель | Значение «как есть» |
| --- | --- |
| Размер пакета `out/template-default.zip` | 865 727 байт (~845 КБ) |
| `styles.css` в пакете | 46 722 байт |
| Классы `ou-*` в `styles.css` | 0 (дизайн-система НЕ вложена) |
| `@font-face` в `styles.css`/`index.html` | 0 (шрифт НЕ вендорится) |
| Упоминаний `RostelecomBasis` | 0 |

Вывод: подтверждает исходное состояние из спеки — собственный CSS шаблона (~1120
строк `theme.css` + `base.css`) без токенов/компонентов DS; брендовый шрифт в пакете
отсутствует, поэтому в LMS без него текст уезжает на системный. После фазы 1
ожидается: `ou-*` присутствуют, `@font-face RostelecomBasis` присутствует, вес zip
вырастет на сжатый DS (~+45 КБ по оценке спеки) — зафиксировать здесь повторным
замером.

## Замер после вендоринга DS + шрифта (фаза 1, задача 1.3)

Дата: 2026-07-26. Команда `npm run scorm:template`.

| Показатель | «Как есть» | После 1.3 | Дельта |
| --- | --- | --- | --- |
| `out/template-default.zip` | 865 727 байт | 1 081 242 байт (~1056 КБ) | +~190 КБ |
| `styles.css` в пакете | 46 722 байт | 380 870 байт | +334 КБ (несжатый DS) |
| Классы `ou-*` в `styles.css` | 0 | есть (`.ou-radio-card`, `.ou-btn`, …) | — |
| `@font-face RostelecomBasis` | 0 | 4 начертания -> `assets/fonts/*.woff2` | — |
| Файлы шрифта в zip | 0 | 4 woff2 (~39 КБ каждый, ~156 КБ) | — |

Оценка спеки (+45 КБ) была занижена: несжатый DS ~334 КБ, но в zip (deflate)
даёт ~+34 КБ, основной прирост веса — 4 woff2 (~156 КБ). Браузерная приёмка в
SCORM-плеере (`.playwright-mcp/player`): DS применяется к `.ou`-разметке
(`ou-btn--primary` берёт акцент, `ou-radio-card` -> `display:flex`), мост палитры
разрешается в пакете (`--ou-purple-500` -> `hsl(217 91% 42%)` — синий теста),
шрифт RostelecomBasis грузится из пакета (`fonts.load` -> loaded), текущий
(домиграционный) стартовый экран рендерится без регресса.
