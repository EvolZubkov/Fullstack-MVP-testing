# Три режима ввода текста задания (PRD-57, этап Э13): план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** текст задания набирается в любом из трёх режимов, и листинг, формула и пропуск
работают во всех трёх; переключение не теряет содержимого молча.

**Architecture:** формат — колонка вопроса, как у обратной связи и у описания теста. Выдача
ветвится в ОДНОМ месте (`promptHtmlOf`); санитайз, типографика по узлам, подсветка и
формулы берутся у существующих модулей.

**Tech Stack:** TypeScript, Drizzle + PostgreSQL, React 19, `@skillum/ui-kit`, Vitest.

**Устройство согласовано:**
[docs/specs/2026-09-20-prd57-e13-input-modes-design.md](../specs/2026-09-20-prd57-e13-input-modes-design.md).
Требования: [PRD-57](../specs/prd-57/open-response-and-formatting.md) §4.3, AC-01b.

**Границы.** Не делается: изображения в тексте задания, таблицы в разметке, свой санитайзер,
внешняя библиотека RTE.
