# Заполнение пропусков (PRD-57, этап Э8): план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** тип задания «Пропуски»: поля ввода внутри текста, правила на каждый пропуск,
оценка счётчиками и одно взаимодействие в LMS.

**Architecture:** пропуск — это `AnswerRuleSet` с именем, поэтому весь аппарат Э4 — Э7
работает без правок. Новое: разбор разметки, подстановка маркера (одна на все места без
полей) и рендер полей в слот текста задания.

**Tech Stack:** TypeScript, Zod, React 19, `@universityrt/ui-kit`, Vitest.

**Устройство согласовано:**
[docs/specs/2026-09-19-prd57-e8-blanks-design.md](../specs/2026-09-19-prd57-e8-blanks-design.md).
Требования: [PRD-57](../specs/prd-57/open-response-and-formatting.md) §6, FR-24 — FR-26.
Эскиз: `docs/wireframes/approved/prd57-blanks-editor.html`.

**Границы этапа.** Не делается: вес пропуска (его нет по решению владельца), развёрнутый
ответ (Э9), книга Excel (Э10).
