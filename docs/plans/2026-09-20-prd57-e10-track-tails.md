# Хвосты трека (PRD-57, этап Э10): план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** новые типы и новая разметка доезжают туда, где у остальных типов всё работает с
прошлых треков: периметр защиты, книга Excel, импорт выгрузки LMS, аналитика, замер времени.

**Architecture:** нового поведения для участника нет. Каждый хвост — ветка для трёх новых
типов в уже существующем механизме; ни один из них не заводит второй копии правил.

**Tech Stack:** TypeScript, Zod, React 19, Vitest, ExcelJS.

**Устройство согласовано:**
[docs/specs/2026-09-20-prd57-e10-track-tails-design.md](../specs/2026-09-20-prd57-e10-track-tails-design.md).
Требования: [PRD-57](../specs/prd-57/open-response-and-formatting.md) §7.

**Границы этапа.** Не делается: обработка текста моделями, интерфейс проверяющего (PRD-58),
замеры на стенде WebTutor (#51).
