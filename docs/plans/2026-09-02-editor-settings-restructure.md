# План: перестройка настроек редактора теста и подытоги без вердикта

> **Исполнителю:** ОБЯЗАТЕЛЬНЫЙ ПОДНАВЫК — вести работу задача за задачей через
> `superpowers:subagent-driven-development` либо `superpowers:executing-plans`.
> Шаги помечены чекбоксами (`- [ ]`) для отметки готовности.

**Цель:** привести редактор теста к целевому дереву из
[аудита](../reports/AUDIT_TEST_EDITOR_SETTINGS.md) §3.1 и убрать из расчёта подытогов вердикт
подтемы: подтема считается и показывается, но не судится.

**Источники решений:** аудит §3.6 (двадцать решений владельца),
[PRD-50](../specs/prd-50/result-breakdowns.md) §15 (FR-49 - FR-51),
[PRD-29](../specs/prd-29/measurement-results.md) §7.1a (обратная связь темы — замена),
[PRD-19](../specs/prd-19/skip-return-navigation.md) §3.1 (FR-11a - FR-11d).

**Целевое дерево верхнего уровня:** Основное · Состав и сценарий · Правила прохождения ·
Оценка результата · Обратная связь и итоги · Оформление.

## Границы

В плане: расчёт подытогов, обратная связь на подтему, перестройка вкладок и рейлов,
переименования с алиасами книги, свободная навигация внутри раздела, правка поставляемых
шаблонов и контракта, документация, приёмка.

Вне плана: перевод существующих тестов с блоков разделов на подтемы (отдельная работа с
данными заказчика), медиатека, психометрическая аналитика.

## Риски и грабли

- **Вердикты существующих тестов поедут.** Тесты с порогами ключей после перепубликации начнут
  считать тему пройденной там, где раньше её проваливала подтема. Решение владельца: это
  исправление, а не регресс. Сданные попытки не меняются — их результат заморожен снимком.
- **Правка шаблона не видна без перезалива.** Реестр читает копию в `uploads/templates/<id>`;
  файл репозитория приложению не виден.
- **Экспорт опубликованного теста берёт снимок.** После правок пакет остаётся прежним, пока не
  сделана перепубликация.
- **Мок хранилища.** Новый метод `IStorage`, который читает маршрут тестов или попыток, ломает
  разом восемь файлов с моками; точечные прогоны этого не показывают.
- **Книга Excel — контракт.** Переименование параметра без алиаса ломает уже выданные книги.
- **Полный прогон на загруженной машине** не стартует: помогает `TEST_MAX_WORKERS=2 npm test`.
