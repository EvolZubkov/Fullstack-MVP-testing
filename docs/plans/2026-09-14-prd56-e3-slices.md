# PRD-56, этап Э3. Срезы и очередь «требует внимания» — план работ

> **Для исполнителя:** задачи выполняются по одной, сверху вниз, в режиме TDD: сначала падающий
> тест, потом минимальная реализация, потом прогон, потом коммит. Шаги отмечены чекбоксами
> (`- [ ]`).

**Цель:** дать оценщику два инструмента поверх реестра — срезы (кого учили и с каким
результатом) и очередь дел, которая говорит «сделай», а не «посмотри». Заодно снять с экрана
величины, которые нельзя интерпретировать (FR-12).

**Спецификация:** [FR-06 - FR-12](../specs/prd-56/analytics-rework.md).
**Эскиз (согласован 2026-09-13):** [раздел «Аналитика»](../wireframes/prd56-analytics-section.html),
состояния `slices`, `slice-gap`, `compare`, `compare-many`, `save-slice`, `attention`.
**Предыдущие этапы:** [Э1 — слой наблюдений](2026-09-13-prd56-analytics-rework.md),
[Э2 — реестр](2026-09-14-prd56-e2-registry.md).

## Что нужно знать до начала

- **Vitest только через npm:** `npm test -- <путь>`; полный прогон — по разрешению владельца.
- **Дев-сервер не подхватывает серверные правки** — после них перезапуск руками.
- **Приёмка в браузере:** `node scripts/check/acceptance-shot.mjs` и `acceptance-click.mjs`
  (в Git Bash с `MSYS_NO_PATHCONV=1`). Учётка `acceptance@local.test`.
- **UI только из ui-kit**; не хватает пропа — правится `vendor/ui-kit`.

## Состояние на начало работ

- Слой наблюдений умеет всё, на чём стоят срезы: фильтры по тесту, группе, источнику, исходу и
  периоду, порции и общее число. Группа уже значит членство человека (`user_groups`) плюс метку
  импорта — FR-09 выполнен на уровне выборки.
- Реестр и его окно условий работают; язык условий готов к переиспользованию (FR-07b требует
  ровно того же набора).
- Сохранённых наборов условий нет: `FilterBar` умеет их показывать (`savedSets`), но в продукте
  ничего не хранит. Срез = сохранённый набор условий (FR-07b), значит нужна таблица.
- Назначения лежат в `test_assignments`, срок — `due_date` (nullable). `storage.getAllAssignments`
  есть. Попытки и их состояния — в общем слое наблюдений.
- Порога наблюдений (FR-06d) в конфигурации НЕТ: раздел `analytics` содержит только
  `lmsImport`. Порог заводится этим этапом.
- «Обзор» по-прежнему кормится `combined-full` и показывает средние по всем тестам — то, что
  FR-12 велит убрать.

#### Что нашла приёмка и что исправлено

- **Отбор по исходу терял адаптивные прохождения.** Исход считается дважды — в сервисе и в
  запросе, — и выражения разошлись: срез «не сдали» показывал ноль при непустом тесте. Там же
  нашлось второе расхождение: попытку с посчитанным результатом, но без отметки времени, запрос
  считал незавершённой.
- **Вкладка срезов была без рамки расчёта**: период задать было нечем (FR-07i, FR-07j).
- **Очередь была одной таблицей** вместо четырёх корзин эскиза, а позиции — без чисел, по
  которым принимают решение.
- **Чипы условий показывали идентификаторы** вместо названий теста и группы.
- **Над таблицей висело голое число** — счётчик тулбара `DataGrid` без заголовка.

#### Отложено сознательно

- Разворот строки среза по темам и колонка «слабое место» (FR-06e) — вместе с подытогами по
  темам в Э4.
- Меню строки среза («переименовать», «удалить»): ручек нет, спека их не требует.
- Группа в позиции очереди: сервер её не отдаёт, а ради одной подписи тянуть членство на каждую
  строку дорого.

## Риски

- **Порог наблюдений — новая настройка.** Он решает, где показывать процент, а где «мало
  данных», то есть влияет на каждое число экрана. Значение по умолчанию нужно согласовать с
  владельцем до реализации задачи 2, а не выбирать в коде.
- **Срез и сохранённый набор условий — одна сущность.** Если развести их «пока что», в продукте
  появится второй язык отбора, и дальше их уже не сведут. Задачи 1 и 5 делаются с этим
  допущением с самого начала.
- **Снятие `combined-full` (задача 7) трогает весь экран.** Делать его последним, когда срезы и
  очередь уже стоят на своих местах: иначе «Обзор» останется пустым.
- **Оси разбиения легко расползаются.** В объём входят только те, для которых данные уже есть
  (FR-06a); оргструктура не появляется ни под каким видом (FR-06b).
