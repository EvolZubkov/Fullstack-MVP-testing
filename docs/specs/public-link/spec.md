# Публичная ссылка на тест: этап 1

Дата: 2026-10-12. Статус: согласовано владельцем, к реализации.

## Цель

Автор получает публичную ссылку на опубликованный тест. Любой, у кого есть ссылка, проходит
тест без входа в систему и видит экран итогов по настройкам теста. Прохождение НЕ сохраняется:
на сервере не появляется ни участник, ни попытка, ни строка телеметрии или аналитики.

## Решения

- **Механика прогона** — та же, что у отладчика (PRD-18) и окна рецензента (PRD-52): пакет SCORM,
  собранный с `telemetry: null`, раздаётся same-origin, SCORM API живёт в окне-родителе
  (`server/scorm/debug-player/assets/shim.js`, состояние в `localStorage`).
- **Источник пакета** — то, что получают ученики (`buildScormExportData(id, { source: "export" })`):
  опубликованный снимок, а для теста, опубликованного до появления снимков, — живое содержимое.
  Ссылка работает, пока тест опубликован.
- **Кеш** — собранный пакет хранится в памяти и общий для всех посетителей. Ключ: `snap:<id снимка>`
  (без срока жизни; новая публикация даёт новый ключ) или `live:<updated_at теста>` для теста без
  снимка. Живые записи живут 10 минут: правка вопросов в банке не меняет `tests.updated_at`, и без
  срока посетители видели бы старое содержимое бесконечно.
- **Хранение** — отдельная таблица `test_public_links` (одна строка на тест на этом этапе).
  Не колонка в `tests`: строка теста целиком уходит в снимки публикации и в ответ
  `/api/learner/tests`, токен разъехался бы по ним.
- **Права** — `tests.edit` плюс область `edit` теста (как у отладчика).
- **Имя участника в пакете** — «Участник».

## Поверхность

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/tests/:id/public-link` | `{ url: string \| null, published: boolean }` |
| `POST /api/tests/:id/public-link` | выпустить или перевыпустить ссылку; `409`, если тест не опубликован |
| `DELETE /api/tests/:id/public-link` | выключить ссылку |
| `GET /p/:token` | страница-хост: шим и iframe с пакетом |
| `GET /p/:token/shim.js` | шим SCORM API |
| `GET /p/:token/play/*` | файлы пакета |

Ссылка неизвестна, выключена или тест не опубликован: `404` и простая страница
«Ссылка недействительна».

## Интерфейс

Пункт «Публичная ссылка» в меню действий теста в списке «Тесты» (только для опубликованного
теста и при праве `tests.edit`). Окно: ссылка с кнопкой «Копировать», «Выпустить новую»,
«Выключить»; без ссылки — пояснение и «Включить».

## Вне охвата этапа 1

Несколько ссылок на тест, срок действия, предел прохождений, группа, режим показа итогов,
запись прохождений и аналитика, ограничение частоты запросов.
