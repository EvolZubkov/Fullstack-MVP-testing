# Приёмочная матрица — PRD-13 (ролевая модель доступа)

Документ фиксирует приёмку трека PRD-13 (Фаза 5, задачи T-31 и T-32): соответствие
критериям приёмки `AC-01`..`AC-14` из [role-based-access-control.md](../prd-13/role-based-access-control.md),
способ проверки каждого критерия и кросс-ролевые сценарии. Нормативная матрица прав —
[role-model.md](role-model.md).

Обозначения столбца «Проверка»:

- Авто — покрыто автоматическим тестом (`vitest`), файл указан.
- E2E — проверено в браузере (Playwright) на dev-сборке.
- Старт — проверяется поведением при запуске сервера (автопровижининг).
- Lint — проверяется `npm run lint:md`.

## Кросс-ролевые сценарии

Ключевые комбинации «субъект — объект — действие», проверяющие область видимости и потолок.

| Субъект | Объект/контекст | Действие | Ожидание |
| --- | --- | --- | --- |
| Автор | свой тест (владелец) | правка/публикация/экспорт/удаление | разрешено |
| Автор | чужой тест без гранта | правка | запрещено |
| Автор | чужой тест с грантом `edit` | правка/публикация/экспорт | разрешено |
| Автор | чужой тест с грантом `edit` | удаление | запрещено (только владелец) |
| Автор | чужой тест с грантом `assign` | правка | запрещено |
| Менеджер | тест с грантом `assign` | назначение | разрешено |
| Менеджер | тест с грантом `edit` | назначение | разрешено (`edit` включает `assign`) |
| Менеджер | тест без гранта | назначение | запрещено |
| Менеджер | любой тест | правка/выдача доступа/смена владельца | запрещено |
| Администратор | любой тест | правка/назначение/доступ/владелец | разрешено (минует область) |
| Администратор | назначение роли «Администратор» | смена ролей | запрещено (только суперадмин) |
| Менеджер | создание пользователя | выбор ролей | только «Обычный пользователь» |
| Суперадмин (конфиг) | — | весь доступ + автопровижининг при старте | разрешено |
| Автор + Менеджер | — | права | объединение (правит свои + назначает по грантам) |

## Клиент: область видимости в списке тестов

Дерево тестов сервер фильтрует по `readableTestScope`; действия строки гейтятся по праву
(`tests-list.tsx`). Проверено `tests-list.test.tsx` и E2E:

- Автор видит «Редактировать», «Аналитика», меню «Ещё»; не видит «Назначить».
- Менеджер видит «Назначить», «Аналитика»; не видит «Редактировать» и меню «Ещё».
- «Общий доступ» в меню — только при праве `tests.access.grant` (администратор/суперадмин).
- Колонка «Владелец» показывает имя владельца (резолв на сервере, `GET /api/tests`).
