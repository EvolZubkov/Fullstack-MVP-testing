# PRD-50: приёмка этапов Э1, «Э1-доделка» и Э2 в браузере

Дата: 2026-08-14. Ветка `prd-50-result-breakdowns`, стенд `PORT=8098 npm run dev`, dev-БД
с применёнными миграциями `0019_prd50_breakdown_display` и `0020_prd50_breakdown_rules`.

Тест приёмки: «Сертификационный тест для руководителей» (`89e2a5e9`) — тот самый, что собран из
разобранной книги: 8 разделов, 11 тегов, квоты, три варианта выдачи.

## Что проверено

### 1. Порог ключа задаётся и переживает сохранение

Вкладка «Состав» → «Структура», тема «О компании». Переключатель «Пороги по подтемам (тегам)»
включён, у подтемы «Стратегия компании» выбрано «Не менее, %» со значением 80. После сохранения
и перезагрузки редактора значение на месте.

В базе:

```json
{"axis":"tag","keys":{"Стратегия компании":{"type":"percent","value":80}}}
```

### 2. Вариантный режим — то, ради чего таблицу переделывали

У теста включены варианты, поэтому квоты выдачи заблокированы с подписью «Недоступно: активен
режим „Варианты теста“ — вопросы берутся из выпавшего варианта целиком». Переключатель порогов
при этом ЖИВОЙ (`disabled: false`), таблица раскрывается, строки собираются из тегов темы.

Столбец «В вариантах» показал по каждой подтеме: «Вариант 1: 4 · Вариант 2: 4 · Вариант 3: 4»
для «Стратегии компании», 5·5·5 для «Продуктов компании», 7·7·7 для «Корпоративной культуры»,
итого 16 на вариант. Это в точности совпало с квотами книги (4 + 5 + 7 = 16) — то есть автор
видит состав выдачи ДО публикации, как и задумано.

### 3. Полосы и вердикт ключа на итогах

Прогон через отладочный проигрыватель (PRD-18): 13 вопросов отвечено, остальные пропущены,
общий результат 6 %, «Не пройден». На экране итогов в карточках тем:

- **11 строк разреза** — ровно 11 тегов теста;
- у каждой полоса, ширина которой равна значению, и число (настройка «Полоса и число»);
- **«Стратегия компании» — 13 %, класс `is-fail`, подпись «Не пройдено»** — единственный ключ,
  которому задан порог;
- у остальных десяти ключей ни класса, ни подписи: порога нет, вердикта нет.

### 4. Предупреждения при публикации

Публикация теста прошла УСПЕШНО, после неё показан диалог «Тест опубликован с замечаниями»:

- «Тема „О компании“: заданы и квоты, и варианты. В режиме вариантов квоты не применяются»
  (и то же для «Корпоративных финансов», «Технологий», «Правовых основ»);
- **«Тема „Технологии“: вопросов вне вариантов — 2. Они не будут выданы никогда»**.

Последнее замечание — независимое подтверждение находки разбора книги: вопросы `q116` и `q140`
не входят ни в один вариант. Сервис нашёл их сам, на живых данных.

## Что НЕ проверено

- **PDF-отчёт**: кнопка «Скачать отчёт» на экране итогов не нажималась — рендер PDF в отладочном
  проигрывателе требует отдельного прогона.
- **Экран итогов раздела** полос не печатает — это известный долг, записанный в план Э2:
  раскладка `section-results.html` разрезов не получает, хотя сервер их для этого экрана считает.
- **Адаптивный режим**: разрезы считаются (Э1-доделка), но карточка адаптивной темы полос не
  печатает по решению плана — отдельное решение владельца.

## Следы, оставленные приёмкой

В тесте `89e2a5e9` остались: порог 80 % у подтемы «Стратегия компании» и настройка показа
«Полоса и число». Статус возвращён в «черновик». Снимок публикации (один) остался — снимки
неизменяемы по построению. Если демо-настройки не нужны, их снимает автор в редакторе.
