## A-02. Импорт книги опросника

Импорт выполнен настоящим сервисом `importWorkbook` против dev-базы, без моков.

| Что | Результат |

| Вклады вопросов | 132 строки по 22 вопросам |
| Оценка | 22 строки |
| Структура | 1 раздел |
| Ошибок | **0** |
| Предупреждений | 22 |

Проверка в базе: 22 вопроса типа `scale`, из них измерительных 22, с шестью
градациями 22.

Предупреждения — это FR-25: книга Маслача выставляет «веса: 0 # 1 # … # 5» каждому
измерительному вопросу, а вклад в шкалы задан отдельно листом «Вклады вопросов».
Веса на результат не влияют и сохранены как есть; импорт честно сообщает об этом по
одному разу на строку. Наблюдение к обсуждению: 22 одинаковых предупреждения — это
шумно, стоит подумать про схлопывание однотипных в одно с указанием числа строк.

## A-04. SCORM-пакет в настоящем браузере

Пакет собран из ЖИВОГО состояния теста тем же сборщиком `buildScormExportData`, что
использует роут выгрузки, и проигран в локальном плеере (`npm run scorm:player`)
полным Chromium через CDP.

- В пакете 22 вопроса типа `scale`; в рантайме доступны `TBTemplate.renderScale` и
  `TBQType.isSingleIndexChoice`.
- Разметка: `role="radiogroup"`, шесть шагов, подписи градаций в авторском порядке,
  bullets ПУСТЫЕ, ширина bullet 44px, размер подписи 22px.
- Клавиатура: три нажатия «вправо» с неотвеченного состояния дали
  последовательность −1 → 0 → 1 → 2; статусы `is-done, is-done, is-current`;
  в состоянии рантайма сохранился ответ `2`.
- Шкалы PRD-5 подхватили вклад: `reduced_personal_accomplishment.raw = 2` — индекс
  градации стал значением шкалы ровно так, как задано листом «Вклады вопросов».
- Адаптив: при ширине 620px шкала автоматически встала вертикально, при 1440px —
  горизонтально (`flex-direction: row`). Оба состояния сняты.

Снимки: `.playwright-mcp/scorm-01-start.png`, `scorm-02-scale.png`,
`scorm-03-answered.png` (вертикальная раскладка), `scorm-04-wide.png`

## Замечания, найденные приёмкой

1. Тема опросника уже существовала в dev-базе с 22 вопросами прежнего типа, поэтому
   раздел теста набрал 44 вопроса. На проверку это не повлияло (шкальные вопросы
   отрисовались и посчитались корректно), но при повторной приёмке стоит заводить
   отдельную тему, чтобы не смешивать наборы.
2. Magic link только аутентифицирует: приложение открывает последнюю попытку
   учащегося, а не назначенный тест. Для приёмки пришлось переходить на маршрут теста
   явно. Это поведение существующее, к PRD-26 отношения не имеет.
