# Красный ствол 2026-08-09: разбор и починка

Дата: 2026-08-09. Ветка `prd-47-report-measures`.

Полный `npm run test:cov` не проходил с начала августа: 87 падений в 12 файлах (замер
2026-08-08 давал 88 — набор файлов тот же). Пока прогон красный, покрытие не считается
вовсе: каталог `coverage/` не создаётся, и порог 80 % не с чем сравнивать.

Ниже — что стояло за каждым падением. Причин оказалось четыре, и две из них были ЖИВЫМИ
дефектами, а не устаревшими проверками.

## 1. Фикстура pglite отстала от схемы — 83 падения

`tests/it/schema.sql` не знал двух колонок таблицы `tests`: `question_order` (PRD-30,
миграция `drizzle/0011`) и `quick_advance` (PRD-43, `drizzle/0012`). Любой `insert into
"tests"` в pglite падал с `column ... does not exist`, а с ним — все репозиторные наборы:

| Файл | Падений |
| --- | --- |
| `storage/tests-repository` | 28 |
| `storage/scales-variables-repository` | 22 |
| `storage/assignments-repository` | 12 |
| `storage/content-pages-repository` | 9 |
| `storage/topics-repository` | 5 |
| `storage/folders-repository` | 4 |
| `storage/access-repository` | 1 |
| `storage/schema-export-parity` | 1 |

Последний — сторожевой тест, который прямо называет обе недостающие колонки; он работал,
просто его никто не читал.

Заодно выровнена третья расхождение, которое сторож поймать не мог (он сверяет наличие
колонок, не их обязательность): у `test_sections.question_order` в фикстуре остались
`DEFAULT 'random' NOT NULL`, снятые той же миграцией `0011`, — а в `shared/schema.ts` эта
колонка nullable, потому что NULL означает «как в тесте».

Настоящие миграции в порядке: обе колонки есть в `drizzle/`. Отставала только фикстура.

## 2. Смоук перестал ловить пустой экран — 1 падение, ЖИВОЙ дефект

Тест «ломаный макет отчёта — БЛОКИРУЮЩАЯ ошибка, а не молчание» подставлял пустой макет и
ждал провала строки. Строка проходила.

Причина: `applyProtection` (PRD-34) вставляет свой `<style>` в КАЖДЫЙ отрисованный корень
безусловно — лист несёт правила печати, водяной знак и вуаль расфокуса. С этого момента
`root.innerHTML` не бывает пустым, и проверка «Экран отрисован пустым» замолчала. Молча:
экран, который не отрисовал ничего, выглядел для гейта активации ровно как экран, который
отрисовал всё.

Это не проверка отстала — это сторож активации шаблона перестал сторожить. Пустой макет
любого экрана (не только отчёта) прошёл бы гейт и уехал бы в LMS.

Починено в `shared/template/smoke-runner.ts`: перед вердиктом из корня вычитается то, что
добавил РАНТАЙМ. Атрибут листа защиты для этого вынесен в экспорт
(`PROTECTION_STYLE_ATTR`), чтобы строка не жила в двух модулях копиями.

## 3. Арифметика ожидаемых строк смоука отстала — 1 падение

`report.total` считался как «экраны + виды отчёта», а проверка добавляет ещё строку якоря
водяного знака (`checkWatermarkAnchor`, PRD-34): 28 против ожидаемых 27. Ожидание
поправлено именованной константой с объяснением, что это за строка.

## 4. Дрейф шаблонов — 2 падения

- **`template-scene-css`**: в слое сцены `theme.css` оказался цветовой литерал
  `rgb(0 0 0 / 0.85)` — затемнение полноэкранного просмотра медиа (PRD-38). Правило слоя:
  палитра только через токены `--ou-*`. Заменено на `var(--ou-bg-backdrop)` — тот же токен,
  которым затемняют фон модалка и ящик ДС. **Внимание: это видимая правка.** Затемнение
  становится легче (0.66 в тёмной теме, 0.48 в светлой против прежних 0.85), зато следует
  теме; если для просмотра картинки нужен именно плотный фон, нужен свой токен в ДС, а не
  литерал в шаблоне.
- **`template-layout-parity`**: `results.html` «Сертификации» нёс старую редакцию
  комментария PRD-46. Приведён к «Стандартному» — паритет этих макетов держится вручную,
  и тест существует ровно для этого.

## 5. Сторож порядка палитр считал лишний лист — 1 падение

`template-screen.test.tsx` (PRD-23) требовал, чтобы блок темы был ПОСЛЕДНИМ листом стилей
в теневом корне. Последним стал лист защиты из пункта 2 — он попадает в корень при
отрисовке. Палитры он не несёт (правила печати и уведомление), поэтому на то, чей цвет
победит, не влияет. Проверка сужена до листов, которые палитру несут.
