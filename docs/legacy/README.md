# Wireframes legacy reference

Reference-документы. Не мигрируются на UniversityRT Design System.
Используются как источник содержания для `prd7-*` wireframes.

## Файлы

- `design-tab.html` — историческая выкладка вкладки "Оформление" Drawer.
- `pages-tab.html` — историческая выкладка вкладки "Структура" Drawer.
- `ds-component-mapping.html` — карта соответствия legacy-классов и DS.

## Статус

`design-tab.html` и `pages-tab.html` помещены сюда временно для
исключения из gate-проверки DS. Они остаются **референсом по содержанию**
для соответствующих вкладок Drawer (формы, состояния валидации,
dirty/saving/read-only, галерея шаблонов, превью, мэппинг страниц,
drag-and-drop тем). Финальный перенос в статус "deprecated" возможен
только после появления согласованных Drawer-эскизов "Оформление" и
"Структура", полностью покрывающих содержание этих файлов.

## Правила

- Не редактировать. Используются только для справки.
- Не покрываются `npm run check:wireframes:ds` (директория `legacy/`
  целиком в `ignoreDirs` gate-скрипта).
- При работе над PRD-7 Drawer использовать как источник правды по
  содержанию вкладок: список параметров, секции, состояния, валидация.
- Расхождения с `architecture/test-settings-parameter-structure.md` по контейнеру
  (Drawer vs page) трактовать как ожидаемые: контейнер будет приведён
  в соответствие в новых Drawer-эскизах.
